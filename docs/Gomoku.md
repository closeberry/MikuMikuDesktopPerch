# 五目並べ（ミニゲーム）の設計

キャラクターと1対1で打つ五目並べです。麻雀・花札・オセロと同じ和室の卓に、キャラクターが座って相手をします。

## 方針

- **麻雀・花札・オセロと同じ作り**：別のウィンドウで遊び、キャラクターはその間デスクトップから消えて、同じモデルが卓の向こうに座る。
  部屋・卓・椅子・入ってきて座るまで・カメラの操作・吹き出し・観戦・デスクトップに戻ってからのひと言は同じ。
- 右クリックメニューの「ミニゲーム」→「五目並べをする」で、そのキャラクターと打つ。いつでも閉じてやめられる（途中のEscは、Yでやめる、Nで続ける）。
- 盤と石はコードで描く（画像は使わない）。

## ルール

- 15×15の盤（線の交わる点に打つ）。黒が先。交互に1つずつ置き、縦・横・斜めのどれかに先に5つ並べたほうの勝ち。
- **黒だけ禁じ手がある**（連珠に近い形）：黒は、三三（一手で「活三」が2つできる）、四四（一手で「四」が2つできる）、長連（6つ以上並ぶ）になる点には置けない。
  ただし、その一手でちょうど5つ並ぶなら置ける（勝ち）。白には禁じ手がなく、6つ以上並んでも勝ち。
  - 四：あと1つで5つ並ぶ形。活四（両側どちらに置いても5つになる）は1つと数える。
  - 活三：あと1つで活四になる三。
  - 禁じ手の点に置こうとしたときは、置けずに「そこは禁じ手（三三）です」などと出る（負けにはしない）。
- 盤が埋まっても決着がつかなければ引き分け。
- 最初の対局の黒（先手）はくじで決め、そのあとは対局ごとに入れ替わる。

## 卓と3D

- 卓の真ん中に碁盤（明るい木の盤、線、星の5つの点）。手前の行があなた側、向こうの行がキャラクター側。それぞれの右手側に碁笥（石の入った入れ物）。
- 自分の番には、カーソルを合わせた点に金色の印が出る。黒の禁じ手の点には赤い×が出る。
  矢印キーで点を選び、Enterで置くこともできる（選んだ点は金色の枠）。
- 最後に置かれた石には赤い点。決着がつくと、5つ並んだ石に金色の点が付き、金色の光が出る。
- 石は上から置かれる（石を打つ音）。キャラクターは、置く前にその点へ手を伸ばす。ときどき考える（そのときはひと言）。
  勝つと拍手か頬に手、負けると「あちゃ～」。
- 左上（相手）と左下（自分）に石の色と手番、右上に何手目か。
- 3Dで描けないときは2Dの画面で、盤を上から見た図にする。
- `--snapshot out.png 560 --gomoku [moves]` で3Dの卓を撮る（movesを指定すると、12秒後にその手数だけ両方の手を打つ）。
  `--gomoku-shot out.png [moves] [seed]` で2Dの画面を撮る。

## キャラクターの打ち方

- 盤の上はすべて見えているので、置ける点それぞれについて、そこに置いたときにできる形（五・四・活三・二など）の値打ちと、
  相手がそこに置いたときにできる形の値打ち（そこを止める値打ち）を足して、一番高い点に打つ。深く先読みはしない（そこそこの強さ）。
  - 自分が5つ並べられるときは必ず並べ、相手の四は必ず止める。四と活三が同時にできる点は高く見る。
  - 黒のときは、自分の禁じ手の点には打たない。
- いつも一番いい手を打つとは限らない（ときどき次にいい手を打つ。ただし勝てる手や、止めないと負ける手のときは崩さない）。

## 音

麻雀・花札の音の仕組み（`src/MahjongSound.cpp`）の札の音を使う：石を置く「パチッ」。3Dの卓では、石が着いたときに鳴る。

## しゃべる五目並べ・観戦

麻雀などと同じ。キャラクターが話すのは：対局の始まり、あなたがあと1つで5つ並ぶ形を作ったとき（あわてる）、
キャラクターがあと1つで5つ並ぶ形を作ったとき（いい手）、勝ち確定・負け確定（その手の間、表情も笑顔・しょんぼりに変わる）、
対局の終わり（勝った・負けた・引き分け）。考えるときのひと言も、`res/gomoku/lines.txt` の下書きから選ぶ。
セリフの作り（LLMによる言い直し、ユーザーのセリフファイル）は麻雀と同じで、場面の一覧は `docs/GameLines.md`。
観戦しているキャラクターは、あと1つの形や、終わりで、ときどきひと言いう。デスクトップに戻ると、対局の感想（途中でやめたら、そのこと）をひと言いう。

## なかよし度

対局を最後まで打つと、一緒に打ったキャラクターのなかよし度が上がる（+3、1日に9まで。途中でやめた対局は数えない）。

## 確かめ方

- `--gomoku-test <out.txt>`：決めた局面で、五の勝ち、黒の長連・三三・四四の禁じ手、四三は打てること、片側が止まった三は活三でないこと、
  キャラクターが勝ちを取ること・四と活三を止めることを確かめる。1行目は失敗の数。
- `--gomoku-play-test <out.txt> [count] [seed]`：キャラクター同士（こちら側もキャラクターと同じ打ち方、最初の4手はでたらめ）と、でたらめに打つ相手と、
  それぞれcount回ずつ対局し、盤が食い違わないか・止まらないかを確かめて、勝ち数・手数・一番長く考えた時間を出す。1行目は「0 wrong」。
