## しくみ

ミニゲームでキャラクターが話すセリフは、ゲームごと・場面ごとに用意した下書き（`res/<ゲーム>/lines.txt`）から選びます。その場でLLMに考えさせることはしません。

1. **用意したセリフ**：男女を問わない普通の話し言葉の下書きです。LLMを設定していれば、ゲームを開いたときに、場面ごとにそのキャラクターの口調へ言い換えてもらい、`%LOCALAPPDATA%\MikuMikuDesktopPerch\characters\<モデル名>-<番号>.<ゲーム>.lines.txt`（ババ抜きは `.oldmaid.txt`） に保存して次から使います（名前・人物設定・言語・下書きのどれかが変わると言い換え直します）。言い換えが届く前やLLMがないときは下書きのまま言います（英語のときは、言い換えが届くまでその場面では話しません）。
2. **セリフファイル**（あなたが用意するもの）：書いた場面では、書いたセリフをそのまま言います。LLMで言い換えず、その場面はLLMに頼みもしません。

どちらも、直前に言った4つのセリフはなるべく避けて選びます。

## セリフファイルの置き場所

このアプリのフォルダ（`MikuMikuDesktopPerch.exe` のあるフォルダ）の中に `lines` フォルダを作り、その中に、キャラクターのモデルのPMXファイルの名前で `<PMXのファイル名>.json` を置きます。キャラクターごとに1つです。

- 例：モデルが `D:\MMD\Miku\Miku.pmx` なら `<アプリのフォルダ>\lines\Miku.json`
- アプリの更新では、`lines` フォルダはそのまま残ります（`Example.json` だけは、新しいものに置き換わります）
- **ひな形**：`lines\Example.json` に、全部のゲームと場面を並べたひな形があります（架空のモデル `Example.pmx` 用）。コピーして、キャラクターのモデルのPMXファイルと同じ名前にし、使う場面の `//` を消して書き込みます
- 名前の同じPMXファイル（別のフォルダにある同じ名前のモデル）は、同じセリフファイルを使います
- 既定ではありません。置かなければ、用意したセリフだけを使います
- ゲームを開くたびに読み込むので、書き換えたらゲームを開き直してください（アプリの再起動はいりません）

## 書き方

```json
{
  "ゲームの名前": {
    "場面の名前": セリフ,
    ...
  },
  ...
}
```

場面に書けるものは、次のどれかです。

| 書き方 | 意味 |
|---|---|
| `"よろしくね"` | セリフ1つ |
| `["よろしくね", "負けないよ"]` | セリフをいくつか（言うたびにランダムに1つ） |
| `{"text": "よろしくね", "voice": "hello.wav"}` | 音声付きのセリフ1つ |
| `{"lines": [...], "chance": 0.5}` | セリフと、その場面で話す確率 |
| `{"chance": 0.3}` | 確率だけ変える（セリフは用意したもの） |

セリフ1つは、文字だけなら `"..."`、音声を付けるなら `{"text": "...", "voice": "音声ファイル"}` と書きます。

- **text**：吹き出しに出す文字。省くと吹き出しを出さず、音声だけを再生します
- **voice**：音声ファイル。フルパスか、セリフファイルのあるフォルダからの相対パス。WAV、MP3、AAC（M4A）、FLAC など、Windowsで再生できる形式（10分まで、64MBまで）。指定すると、声（VOICEVOX・AivisSpeech）は使わずにこの音声を再生し、口パクは音声の大きさに合わせ、吹き出しの文字は音声の長さに合わせて出ていきます
- **chance**：その場面で話す確率。0〜1（1より大きい数は％とみなします。`50` は50%）。書かなければ、ゲームが決めている確率です（多くの場面は毎回、「迷う」のように毎回ではない場面もあります）。0にすると、その場面では話しません。ほかのセリフが出ている途中などで、確率に関係なく話さないこともあります

```json
{
  "oldmaid": {
    "最後の1枚": {
      "chance": 1,
      "lines": [
        {"text": "あーあ、負けちゃった", "voice": "voice\\lose1.wav"},
        {"text": "えー、もう終わり？", "voice": "voice\\lose2.mp3"}
      ]
    },
    "勝ち確定": ["これで終わりだよ", "ふふふ"],
    "迷う": {"chance": 0.3},
    "揃えて捨てる": {"voice": "voice\\sigh.wav"}
  }
}
```

### 文字コードと書き間違い

- UTF-8（BOMあり・なし）、UTF-16、Shift-JIS のどれで保存しても読めます（自動で判別します）
- `voice` のパスの `\` は、`\\` と書いても `\` 1つのままでも構いません
- `//` から行末まで、`/*` から `*/` までは、コメントとして読み飛ばします
- `]` や `}` の直前の余分なカンマは許します
- 読めなかったとき（かっこやカンマ、`"` の閉じ忘れなど）、音声ファイルが見つからないとき、ない場面の名前を書いたときは、ゲームを開いたときに知らせます。読めたところは使います

## ゲームと場面の名前

場面の名前は、下の表のとおりに書きます（ほかの名前は使われません）。

### ババ抜き（`oldmaid`）

| 場面 | いつ |
|---|---|
| 始まり | ゲームが始まるとき |
| 揃えて捨てる | 配ったあと、自分の手札の組を捨てるとき |
| あなたの番 | あなたが引く番の始め（キャラクターがジョーカーを持っていないとき。75%） |
| 揺さぶる | あなたが引く番の始め（キャラクターがジョーカーを持っているとき。75%） |
| 誘う | あなたが指したカードを引いてほしいとき（にこにこして勧める） |
| 焦る | あなたが指したカードを引いてほしくないとき（ちょっと焦る） |
| 余裕 | あなたが指しているとき（キャラクターがジョーカーを持っていないとき） |
| 取られた | あなたがキャラクターの手札から引いて組をそろえたとき |
| 引かれた | あなたが引いたカードが組にならなかったとき（ジョーカー以外） |
| 迷う | キャラクターがあなたの手札から引く前（85%） |
| そろった | キャラクターが引いて組がそろったとき |
| 外れた | キャラクターが引いたカードが組にならなかったとき（ジョーカー以外） |
| ジョーカーを引かせた | あなたがキャラクターからジョーカーを引いたとき |
| ジョーカーを引いた | キャラクターがあなたからジョーカーを引いたとき |
| 混ぜる | キャラクターが自分の手札を混ぜるとき（あなたの番の始めの75%のうち3割） |
| 残りわずか | どちらかの手札が残り3枚以下になったとき（1回） |
| 最後の1枚 | あなたの最後の1枚をキャラクターが引くとき（負けが決まる） |
| 勝ち確定 | キャラクターの手札が残り1枚で、あなたが引く番になったとき（勝ちが決まっている） |
| 勝った | キャラクターが勝ったとき |
| 負けた | キャラクターが負けたとき（「最後の1枚」で負けたときは言いません） |

### 麻雀（`mahjong`）

| 場面 | いつ |
|---|---|
| 始まり | 対局が始まるとき |
| オーラス | 最後の局（オーラス）が始まったとき |
| リーチされた | あなたにリーチをかけられたとき |
| 和了った | キャラクターが和了ったとき |
| 和了られた | あなたが和了ったとき（キャラクターから出た、またはツモられた） |
| 流局 | 山がなくなって流局したとき |
| 勝った | 対局が終わって、キャラクターが勝ったとき |
| 負けた | 対局が終わって、キャラクターが負けたとき |
| ポン | キャラクターがポンかカンで牌をもらうとき（ときどき） |
| 考える | キャラクターが次に切る牌を迷って考えているとき |

### 花札（こいこい）（`hanafuda`）

| 場面 | いつ |
|---|---|
| 始まり | 勝負が始まるとき |
| 最後の月 | 12か月目、最後の月（12月）が始まったとき |
| こいこいされた | あなたがこいこいをして、勝負を続けたとき（役を作ったが上がらなかった） |
| 月に勝った | この月の上がりで、キャラクターが勝ったとき |
| 月に負けた | この月の上がりで、あなたが勝って、キャラクターが負けたとき |
| 月が流れた | この月は、どちらも役で上がれずに終わったとき |
| 勝負に勝った | 12か月が終わって、キャラクターが勝ったとき |
| 勝負に負けた | 12か月が終わって、あなたが勝ったとき |
| 勝負が引き分け | 12か月が終わって、引き分けたとき |
| 考える | キャラクターが自分の番に、どの札を出すか迷うとき（ときどき、自分につぶやく） |
| 取る | キャラクターが場から光札を取ったとき（ときどき） |

### オセロ（`othello`）

| 場面 | いつ |
|---|---|
| 始まり | ゲームが始まるとき |
| いい手 | キャラクターがいい手を打ったとき（盤のすみ（角）を取ったときなど。ときどき） |
| 考える | キャラクターが自分の番に、どこに置くか迷うとき（ときどき。自分へのつぶやきで、相手への問いかけにはしない） |
| 角を取られた | あなたが盤のすみ（角）を取ったとき |
| ひっくり返された | あなたの一手で、キャラクターの石が6枚以上まとめてひっくり返されたとき |
| あなたのパス | あなたが置ける所がなくてパスになり、キャラクターがもう一度打つとき |
| 自分のパス | キャラクターが置ける所がなくてパスになり、あなたがもう一度打つとき |
| 勝った | 対局が終わって、キャラクターが勝ったとき |
| 負けた | 対局が終わって、キャラクターが負けたとき（引き分けのときも） |

### 五目並べ（`gomoku`）

| 場面 | いつ |
|---|---|
| 始まり | 五目並べの対局が始まるとき |
| 危ない | あなたがあと1つで五つ並ぶ形を作り、止めないと負けるとき（あわてる） |
| いい手 | キャラクターがあと1つで五つ並ぶ形を作り、あなたの番になったとき（にこにこして言う） |
| 考える | キャラクターが自分の番に、どこに置くか迷うとき（自分につぶやく） |
| 勝ち確定 | キャラクターが次の手で必ず五つ並べられ、あなたには止められないとき（にこにこして勝ち誇る） |
| 負け確定 | あなたが次の手で必ず五つ並べられ、キャラクターには止められないとき（しょんぼりして） |
| 勝った | キャラクターが五つ並べて勝ったとき |
| 負けた | あなたが五つ並べて、キャラクターが負けたとき |
| 引き分け | 盤が埋まって、どちらも五つ並ばずに引き分けたとき |

### ブラックジャック（`blackjack`）

| 場面 | いつ |
|---|---|
| 始まり | ゲームが始まるとき（10回の勝負が始まる） |
| 配る | 相手の最初の2枚を配ったあと（ときどき） |
| 引く | ディーラーのキャラクターがもう1枚引くとき（ときどき） |
| 相手のブラックジャック | 最初の2枚で相手が21（ブラックジャック）を出したとき |
| ディーラーのブラックジャック | 最初の2枚で、ディーラーのキャラクターが21（ブラックジャック）になったとき |
| 相手のバースト | 相手が21を超えて負けたとき |
| ディーラーのバースト | ディーラーのキャラクターが21を超えて、相手の勝ちになったとき |
| 相手の勝ち | 1回の勝負で、相手が勝ったとき（キャラクターの負け） |
| ディーラーの勝ち | 1回の勝負で、ディーラーのキャラクターが勝ったとき |
| 負けて終わる | 10回の勝負が終わり、相手がチップを増やしたとき（キャラクターの負け） |
| 勝って終わる | 10回の勝負が終わり、ディーラーのキャラクターが勝ったとき（引き分けも） |
| 勝ち確定 | 伏せたカードを開く前に、この回がディーラーのキャラクターの勝ちに決まったとき（にやり） |
| 負け確定 | 伏せたカードを開く前に、この回がディーラーのキャラクターの負けに決まったとき（落ち込む） |

### エアホッケー（`airhockey`）

| 場面 | いつ |
|---|---|
| 始まり | 対戦が始まるとき |
| 決めた | キャラクターがゴールを決めたとき |
| 決められた | あなたがゴールを決めたとき |
| 長い打ち合いで決めた | 長い打ち合いのあと、キャラクターがゴールを決めたとき |
| 長い打ち合いで決められた | 長い打ち合いのあと、あなたがゴールを決めたとき |
| あと1点で勝ち | キャラクターがあと1点で勝つとき（マッチポイント） |
| あと1点で負け | あなたがあと1点で勝つとき（相手のマッチポイント） |

| 負けた | 対戦が終わって、あなたが勝ったとき |
