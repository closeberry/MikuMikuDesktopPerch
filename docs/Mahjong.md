# 麻雀（ミニゲーム）の設計

キャラクターと1対1で打つ、昔のゲームセンター風の2人打ち麻雀です。
キャラクターも自分の手牌を持ち、見えている牌から考えて打つ。

## 方針

- **サクサク打てる**：2人打ち、東南戦（4局）、キャラクターの番は1秒足らず。1回の対局が15〜20分ほど。
- **別のウィンドウ**で遊ぶ（ダンジョンと同じ）。いつでも閉じてやめられる。
- キャラクターは、麻雀の間デスクトップから消え、同じモデルを卓の向こうに座らせて描く（PMXやモーションを二重に読み込まない）。
- 右クリックメニューの「麻雀を打つ」で、そのキャラクターと打つ。
- **どちらも本物の麻雀**：山はでたらめに混ぜ、和了り・役・点数は正しく計算する。
  キャラクターは、プレイヤーの手牌や山の中身を見ない。
- **キャラクターと一緒にいること**を生かす：吹き出しで話す、和了ると喜ぶ、振り込むと悔しがる、写真に残す。

## ルール

- **2人打ち**：プレイヤーとキャラクターが向かい合う（自風は東と西）。牌は136枚（赤5を各1枚）。
- **チーはなし**。ポン・カン・リーチ・ロン・ツモはある。
- **東南戦**：東1局・東2局・南1局・南2局。親が和了るかテンパイで流局すると連荘（本場は1本300点）。南場の場風は南。
  持ち点は25000点で、どちらかが0点以下になると、その場で終わる（飛び）。
- **点数**：ふつうの4人打ちの計算で出し、ツモでもロンでも、同じ点を相手が払う
  （ツモの点は、4人打ちで3人から受け取る合計）。
- **流局**：山がなくなったら（ツモは1人24回まで。2人打ちでも1局が長くなりすぎないように）。
  テンパイの人が、ノーテンの人から1000点もらう。
- **役**：一般的なもの（喰いタンあり、喰い下がりあり）。数え役満あり、ダブル役満なし、切り上げ満貫なし。
- 王牌は14枚。ドラ表示牌は1枚から、カンのたびに1枚増える。リーチで和了ると裏ドラ。

## プレイヤーの操作

- 手牌は卓の手前に立てて並べる（3Dで描けないときは画面の下に2Dで。いつも理牌済み。ツモった牌は右に少し離して置く）。
- クリックか←→とEnterで切る。
- ツモ・リーチ・カン・ロン・ポン・見送りは、できるときだけ手牌の右上にボタンが出る。ボタンには1から番号が付き、
  数字キーでも押せる（見送りはスペースでも）。ポン・カンを見送るときは、ボタン以外のところ（手牌や卓の上）を
  クリックしてもよい（卓の上はドラッグでなくクリックのとき）。ロンもできるときは、見送りもボタンだけ（大事なので）。リーチは、ボタンのあとで切る牌を選ぶ（テンパイになる牌だけ選べる。Escでやめる）。
  選ぶ間、カーソルを合わせた牌（キーで選んだ牌）を切ったときの待ち牌と、それぞれで和了ったときの点数（ロン。
  フリテンになるならツモ）、見えていない残りの枚数を手牌の下に出す（リーチ・ドラ・赤は数え、裏ドラ・一発などは
  まだ分からないので数えない）。並びきらない分は「…」で省く。`--mahjong-shot out.png 60 <seed> riichi` で、
  初めてリーチできるところでこの表示を撮れる。
- リーチしていないときのツモのボタンには、ツモで和了ったときの点数も出す（「ツモ 2700点」。リーチのあとは裏ドラが
  まだ分からないので出さない）。`--mahjong-shot out.png 200 <seed> tsumo` で、リーチせずに初めてツモできるところを撮れる。
- **リーチ後はツモ切りを自動で**する（和了れる牌のときだけ止まり、ツモかツモ切りを選ぶ）。リーチ後のカンはできない。
- テンパイしていると、手牌の下に待ち牌を出す。フリテンなら「フリテン」と出す。
- 局の終わりには、和了った手・役・点数（流局ならテンパイかどうか）と点の動きを出す。Enterかクリックで次の局へ。
  対局が終わると最終の点数を出し、Enterでもう一度、Escで閉じる。対局の途中のEscは、Yでやめる（Nで続ける）。
- 3Dの卓は、カメラを動かせる。卓の上を右ボタンでドラッグすると回り、中ボタン（かShift＋右ボタン）のドラッグで動き、
  ホイールで寄る・離れる。右ボタンのダブルクリックかF1で元の視点に戻る。左ボタンではカメラは動かない（牌やボタンを押す、
  卓の上のクリックで見送る、だけ）。

## いまの段階

キャラクターはデスクトップから卓に来て座り、3Dの卓で遊べる（`src/MahjongWindow.cpp`）。3Dで描けないときは2Dの画面で、
顔をデスクトップの姿から切り出して画面の左上に出す。キャラクターは対局中に話し、観戦しているキャラクターも解説する（下の「しゃべる麻雀」「観戦するキャラクター」）。記録はこれから。局の進め方は `src/MahjongTable.cpp` の Table。

- 牌の絵：`res/mahjong/tiles.png`（exe に入れる）。象牙の牌に、彫り込んで色を入れた筆文字・丸・竹。
  七筒は斜めの3つと赤の4つ、八索は上がW・下がMの形。
  150×200の牌を10枚ずつ並べる（34種の順、そのあと萬子・筒子・索子の赤5）。
  `--mahjong-tiles out.png` で、全部の牌を手牌と河の大きさで画像にする。
- 結果画面の文字は筆文字（`res/mahjong/brush.ttf`：Yuji Syuku を、この麻雀で書く文字・かな・英数字だけに絞ったもの。
  SIL Open Font License、`licenses/YujiSyuku-OFL.txt`）。名前は、かなと英数字だけならこの筆文字、漢字があればふつうの文字で書く。
  役名の「么」は筆文字にないので「幺」と書く（断幺九など）。
- キャラクターが槓をすることはない。プレイヤーの加槓をキャラクターが槍槓することもない。
- 確かめ方：`MikuMikuDesktopPerch.exe --mahjong-play-test out.txt [対局数] [seed]` で、キャラクターと同じ打ち方をする
  プレイヤーと、簡単なプレイヤー（いちばん孤立した牌を切る）のそれぞれと対局させ、毎手、牌がちょうど4枚ずつ（赤5は各1枚）
  あるか・点数の合計が変わらないかを確かめる（1行目が「0 wrong」なら合っている）。和了・放銃・流局・リーチ・ポンの割合も出す。
  `--mahjong-shot out.png [手数] [seed]` は、その手数まで進めた画面（局が終われば終わりの画面）を画像にする。

## キャラクターの打ち方

キャラクターが使うのは、自分の手牌・両者の河・晒した牌・ドラ表示牌だけ（`src/MahjongTable.cpp` の ChooseDiscard、WantsPon、Safety）。

- **何を切るか**：14枚から1種ずつ切ってみて、**向聴数**（あと何枚でテンパイか）がいちばん進むものを選ぶ。
  同じなら、**受け入れ枚数**（向聴数を進める牌が、自分から見えていない残りで何枚あるか）が多いもの。
  ドラは残しやすく、ひとつだけの字牌（役にならないもの）は先に切る。役牌の対子は残す。
- **リーチ**：門前でテンパイしたら、待ち牌が残っている限りリーチする。
- **和了**：ロンもツモも、できれば必ず和了る。フリテンの決まりはプレイヤーと同じ（役のない形で見逃した牌もフリテンになる）。
- **ポン**：役牌は、向聴数が悪くならないならポンする。役牌を晒したあとや、手がすべて中張牌のとき（喰いタン）は、
  向聴数が進むならポンする。役がなくなるポンはしない。
- **降り**：プレイヤーがリーチしていて、自分がまだ遠い（2向聴以上。1向聴なら半々）ときは、安全な牌を切る。
  安全さは、プレイヤーの河にある牌とリーチ後に見逃された牌（現物）、字牌の見えている枚数、スジ（3つ離れた牌が
  両方とも河にある）、端の牌かどうかで決める。テンパイしていれば押す。
- **ときどき甘い手**：いつも最善ではなく、ときどき2番目・3番目に良い牌を切る（人らしく）。

簡単なプレイヤーとの1000対局では、キャラクターが対局の5割強で勝つ（和了は局の36%、放銃は11%）。
キャラクターと同じ打ち方のプレイヤーとは、ほぼ五分。

## 点数計算

両者の和了りの判定と、キャラクターの打ち方の両方で使う、ゲームの中心の部品。画面から切り離して作り、既知の手でテストする。

- **和了形**：4面子1雀頭（すべての分け方を試す）、七対子、国士無双。
- **役**：分け方ごとに判定し、いちばん高い分け方を採る。
  リーチ・一発・海底・河底・嶺上開花・槍槓・ダブルリーチ・天和・地和は、局の状態から判定する。
- **符**：20符に、面前ロン10、ツモ2、面子・待ち・雀頭の符を足して10符単位に切り上げる
  （平和ツモは20符、七対子は25符、鳴いた平和形のロンは30符）。待ちが何通りにも取れるときは高い方。
  連風牌（親の東）の雀頭は4符。
- **点数**：基本点＝符×2^(翻＋2)。満貫〜役満で頭打ちにし、親は1.5倍、100点単位に切り上げる。
  役満が重なっても役満1つ分。ドラは役があるときだけ数える。
- **同じ部品で**：テンパイと待ち牌、リーチできるか（切るとテンパイになる牌）、向聴数（4面子1雀頭・七対子・国士無双の少ない方）。
  フリテンは、待ち牌と河を比べて進行の側で見る。
- 部品は `src/Mahjong.cpp`。テストは `tests/MahjongHands.txt` に1行1つの手で書き、
  `MikuMikuDesktopPerch.exe --mahjong-test tests\MahjongHands.txt out.txt` で確かめる
  （out.txt の1行目に、確かめた数と合わなかった数。合わないものがあると終了コード1）。

## 卓と3D

- ウィンドウ全体に、卓の向こうのキャラクターを斜め上から見下ろすように3Dで描く。
  卓の上には、両者の河（6枚ずつ、真ん中から手前へ。キャラクターの河は向こう向き）、両者の立てた手牌
  （キャラクターのは背中、プレイヤーのは少し後ろに傾けて表）、晒した牌（それぞれの右）、リーチ棒。
  ボタン・待ち・名前と点数・局とドラは、卓の上に2Dで重ねて描く（カメラを動かしても読みやすいように）。
  3Dで描けないときは、全部を2Dで描く。
- 卓は木の枠と、枠の下まで届く4本の脚のある卓（幕板はない。太ももが卓の下に入る）で、キャラクターは座布団の載った椅子に座る（ひざが座面に当たらないよう、座面はひざより少し後ろから）。
  まわりは和室：板張りの床、腰板と柱のある壁（木のむらはダンジョンの半分ほど。模様5。壁は青海波を薄く押した和紙の壁紙。`GeometryPS.hlsl` の模様4）、
  キャラクターの後ろの左右に明かりの透ける障子（真後ろは壁）、横に掛け軸（水墨の山水と松、落款。`PaintScroll` で
  描いて牌の絵の下に並べる。掛け軸の縦横に合わせて描くので、丸は丸く出る。色は控えめ）と飾り棚、卓の上に提灯のような明かり（卓と部屋だけを暖かく照らす。キャラクターに当てると
  顔が白く飛ぶので当てない）。明かりと障子には柔らかい光のにじみ（グロー）をかける。何も照らさず、手前に重ねるだけ
  （粒子の柔らかい光、`State::roomGlows`）。カメラは部屋の外に出ない。
- キャラクターは椅子に座る。ウィンドウのふちに座る姿勢（Sit）を、椅子の座面をふちとして使う。
  床は座面から腰の高さの半分下か、座ったときに足が下がるところのすぐ下（すねの長いモデルで足が床を突き抜けないように）。
  3Dの卓を開くときに一度座らせて足の低さを測ってから決める（その後で物理は戻す）。椅子と卓の脚はその床まで伸びる。
  スナップショットの `.txt` の `mahjong:` の行に、いちばん低い脚のボーンと床の高さを書く。
  椅子は卓から引いてある。斜め後ろから引いた椅子の前まで歩いてきて、こちらを向いて座り、一拍置いて、少し腰を浮かせて前かがみになりながら椅子ごと前に出る（卓から椅子1つ分離れて（自分の手牌が見え、手が手牌に当たらないように）。カメラは立っている間だけ少し上を見る）。
  手牌はツモっても他の牌が左右に動かないように、いつも同じ位置から並べる。
- **卓の大きさはモデルに合わせる**：座ったときの肩の高さから、卓の高さと奥行きを決める。
  カメラは卓とキャラクターが収まるように引く。
- **卓は固いもの**：卓の天板・枠・脚を、キャラクターの物理と体のめり込み判定に渡す（`SetTableSolids`、
  docs/AirHockey.md の「めり込み判定」）。髪やスカートは卓に当たり、手を伸ばす動きや手ぶりの腕は卓の手前で止まる。
  `--mahjong-reach far` で手を牌まで伸ばし、`--mahjong-solid-lift x` で卓の固いところだけを上半身の長さの x 上げて、
  止まるところを試せる（`.txt` の `penetration:` の行）。

### 手を伸ばして取る（小さいモデルにも）

牌を指でつかむところは描かない。少しファンタジー風に、手で触れた牌が消えて、場に光りながら現れる。

- **打牌**：切る0.6秒前から、手牌の切る牌の方へ上からぽんと触れる（近い方の手。ひじを後ろに引いて手を胸の前まで上げ
  （卓の縁に当たらないように）、牌の方へ少し出した手のひらを下に向けて、軽く下ろして上げ、同じ道で戻す。前には乗り出さない）。
  触れた牌は青白い光の粒と一緒に消え、河に金色の光と一緒にフェードインする（0.6秒。卓の色から浮かび上がる）。
  切る牌は手を伸ばす前に決めておく（`Table::HerNextDiscard`）。3Dの卓では、ツモから打牌までを少し長く（0.65秒）待つ。
- **ツモ**：手は伸ばさず、立てた手牌の右に、光って1枚増える（打牌の手と重ならないように）。
- **ポン**：「ポン！」と言って、晒した牌の方へ上からぽんと触れる。牌は光って現れる。
- 手が牌に届かなくてもよい（触れるのは魔法：牌の方で手をぽんとするだけで牌がワープする）。ねんどろいどのような小さいモデルでも同じ。
- 腕の動きは GeneratedMotion の Reach（座っていても使える反応の動き。tap で上から軽くぽんとするだけ。届くまで伸ばして
  乗り出す使い方もできる。docs/MotionRules.md に従う）。
  `--snapshot out.png 140 --mahjong 12 --mahjong-reach` で、座ってすぐ手牌に触れて、河の牌がフェードインするところを撮れる。
- **リーチ**：牌を横にして切り、点棒を卓に置く。**ポン**：「ポン！」と言って、プレイヤーの河から牌を取る（同じくワープ）。
- **考える**：3Dの卓では、ツモのあとときどき（15%、プレイヤーのリーチ中は45%。自分のリーチのあとはツモ切りなので考えない）、あごに手を当て、自分の手牌に
  目を落として考えてから切る（打牌が2.2秒遅れる。真面目モーフ「真面目」「まじめ」「真剣」があれば0.5入れて、キリっとした顔に）。
- **局の終わり**：キャラクターが和了ると笑顔で、両手を頬に当てるか拍手する。プレイヤーが和了ると「あちゃ～」と、
  手のひらを額に当てて目をつぶり、首をかしげる（Oops）。流局では何もしない。
  3Dの卓では、和了った局の点数表示を3秒待ってから出す（リアクションが見えるように）。
- これらは腕・首・顔だけを動かす手ぶり（GeneratedMotion::EmoteSeated）で、座ったままでも使える。
  入りは0.7秒、抜けは0.9秒かけて、両端の緩やかな曲線でゆっくり動く。
  `--snapshot out.png 175 --mahjong --mahjong-gesture ponder|cheeks|clap|oops` で、座ってすぐの手ぶりを撮れる。
- **テンポ**：キャラクターの番は全部で0.6〜0.9秒。設定で「早送り」にすると、手の動きを省いて牌だけ動かす。

## 音

牌の音は組み込みの WAV ファイル（`res/mahjong/sounds`。44.1kHz・モノラル・16bit。`.rc` の `MAHJONGSOUND`）、
キャラクターの打牌の「シュッ」だけはその場で作る（`src/MahjongSound.cpp`。いくつも同時に鳴らせる。声とは別の出力）。

- 局の始まり（対局の始まりも）：牌を配る音（3Dの卓だけ）。その間に両者の手牌が、少し上から1枚ずつ降ってきて
  フェードインする（親から交互に、それぞれ左から。最後に親の14枚目。1枚が降りきる前に次が降り始め、音の長さに合わせる）。
  降りきるまで局は始まらない。2Dのウィンドウでは牌が動かないので、この音も鳴らさない（かき混ぜる音は使わない）。
- 牌を切る：牌を置く音（3つを順に使い、続けて切っても同じ音にならないようにする）。リーチの打牌は強く置く音と、
  点棒を置く音。ツモ：牌を取る音。
- キャラクターの打牌（3Dの卓）：ワープなので、触れた牌が消えるときに中ほどから下がる柔らかい「ふわっ」、河に
  現れるときになめらかに上がって消える「ふわっ」と、そっと置く音（鋭い音・きらめくような音にはしない）。
  2Dのウィンドウでは普通に置く音。
- ポン・カン：牌を晒す音（それぞれ別。加槓・暗槓もカンの音）。
- 和了・流局・対局の終わりには音を鳴らさない。
- `--mahjong-sounds <フォルダ>` で、全部の音を WAV ファイルに書き出す（聞いて確かめる用）。
- 降ってくる牌の透け方は、3Dの描画で点を間引いて表す（`GeometryPS.hlsl`。頂点の `uv` の4つ目が透け具合）。
  `--snapshot out.png 16 --mahjong` で、配っている途中を撮れる。

## 観戦するキャラクター

- ほかのキャラクターがデスクトップにいるときは、麻雀のウィンドウが出ている間（最小化していないとき）、観戦する
  （`UpdateWatching`、`src/main.cpp`）。
- ウィンドウの前に重なっていれば、近いほうの横へ歩いて避ける（その側に場所がなければ反対側、どちらにもなければ
  広いほうの画面の端）。同じ側に先に観戦している人がいれば（キャラクターの順で数える）、そのぶん少し外側に立つ。
  場所が足りなければ重なってよい（観戦中は、重なったキャラクターが場所を空ける動きもしない）。避けた先では歩き回らず、
  ランダムな仕草や組み込みの待機クリップもしない。ウィンドウを動かせば、その横へ移り直す。
- 体を少しウィンドウのほうへ向け、卓のあたりを見る。8〜20秒おきに、考えるポーズか頷きをする（その間も視線は卓に）。
- 「アクティブなウィンドウに乗る」がオンでも、麻雀のウィンドウには乗らない。ウィンドウが閉じれば元どおりに過ごす。
- **観戦者の解説**：上の「しゃべる麻雀」の出来事（リーチはキャラクターのものも）があると、観戦しているキャラクターの1人が、
  自分の頭上の吹き出しでひと言いう（応援・実況・解説。`MahjongOpponent::onEvent` → main の `WatchersHear`）。
  いつも話すわけではなく、重さ7以上は8割、5〜6は5割、それより軽いものは3割。前の解説から、重さ7以上なら6秒、それ以外は15秒あける。
  話せるのは、観戦中で、居眠り・入力欄・ほかのキャラクターとのおしゃべり・吹き出しの表示中・返事の途中でない人。
  LLMがあれば、出来事と局・点数を伝えて自分の言葉で、なければ用意したひと言を言う。
  `--snapshot out.png 1500 --mahjong --mahjong-later 400 --watcher <pmx>` で、観戦者がそろってから（20秒後に）手を進めて試せる
  （`.txt` の `watchers said:` に解説）。
- 歩きは、1コマが長くかかって目的地を通り越したら、そこで止まる（止まらずに画面の外へ出ていた）。
- `--snapshot out.png 600 --mahjong --watcher <pmx>` で（`--watcher` は何度でも）、2人目からを画面の中ほどに置いて観戦させられる（`.txt` に
  各キャラクターの位置と観戦中かどうか。トレースに避けた先と仕草）。

## しゃべる麻雀

- 吹き出しの文字は、デスクトップで声なしに話すときと同じく1文字ずつ出る（日本語は0.12秒、英語は0.045秒に1文字。LLMの返事が
  少しずつ届くときは、届いた分の続きから）。吹き出しの大きさは文全体の大きさ。
- 話している間、キャラクターはこちら（カメラ）を見る（3Dの卓。`MascotModel::LookToward`：頭がいま向いている向きから直す）。
- キャラクターの言葉は、キャラクターの頭のすぐ右の**吹き出し**に出る（3Dの卓で、頭を画面に写したところから。2Dでは右上の
  局の表示の下）。デスクトップの吹き出しと同じく、文字数に合わせた大きさで（ウィンドウの幅の5分の2までは1行、それより長ければ
  折り返す）、左にしっぽ（キャラクターの方へ）。
  読める長さだけ出して消す。
- リーチ・ポン・ロン・ツモの掛け声は、いつも決まったセリフで、すぐに出す（これまでどおり、名前の右に大きく）。
- 話すのは：対局の始まり、プレイヤーのリーチ、オーラスの始まり、和了った・和了られた（役と点数）、流局、対局の終わり
  （勝った・負けた）。重さ（1〜9）があり、軽い言葉は重い言葉を3.5秒のうちは上書きしない。
- **LLMがあるとき**は、そのときの出来事と、局・両者の点数、さっき言ったことを伝えて、自分の言葉で1〜2文話す
  （`MahjongOpponent::talk` → main の `MahjongTalk`。返事は `MahjongHeard` で吹き出しへ）。人物設定となかよし度の話し方に合わせ、
  自分の手牌や待ちは言わない。返事を待つ間は「…」。9秒来なければ、用意したセリフにする。小さな出来事は12秒に1回まで
  （それ以外は用意したセリフ）。重さ6以上（始まり・和了・終わり）は毎回。表情もLLMの気持ちの印で変わり、声の設定があれば声も出る。
- LLMがないとき・使えないときは、出来事ごとに用意した何通りかのセリフから選ぶ。
- **小さなひと言**：場から牌を取ったとき（キャラクターのポン・カン）は1割の確率で、考える仕草のときは毎回、ひと言いう。
  そのたびにLLMに聞くと重いので、対局の始まりにまとめて頼んでおく（`MahjongOpponent::prefetch`。ポン用と考える用を6つずつ、
  「ポン：…」「考える：…」の形で。main の `linesChat`、ふだんの会話とは別の要求。答えは `MahjongLines`）。使ったものは除き、
  残りが2つより少なくなったらまた頼む。ないとき（LLMがない、まだ来ていない）は用意したひと言。
- **対局のあとの感想**：ウィンドウを閉じてデスクトップに戻ると、キャラクターが対局の感想をひと言いう。最後まで打ったときは結果
  （勝ち負けと点数）を、途中でやめたときはそのことと点数を伝える（`MahjongAfterword`、main の `SpeakFirst`。LLMがなければ
  用意したセリフ）。
- 卓で話したセリフ（デスクトップの吹き出しには見えないまま入る）は、戻ったときに消す（`DropGameWords`）。
- 和了ったときと役満のときは、自動でアルバムに写真を残す（Pキーでいつでも撮れる）。
- スナップショットの `.txt` の `mahjong words:` に、出来事と言ったこと（LLMのものには `(LLM)`）を書く。

## 記録

- キャラクターごとに `characters\<モデル名>-<番号>.mahjong.txt`（UTF-8の `キー=値`）。
  対局数、勝った数、和了った回数、いちばん高い和了り（役と点数）、出した役満。
- 対局が終わると、キャラクターが結果を話す。
- 対局を最後まで打つと、なかよし度が+3（1日に9まで。途中でやめた対局は数えない。docs/Bond.md）。

## 作る順番

1. 点数計算（和了形・役・符・点数・テンパイ）と、そのテスト。
2. 局の進行（ツモ・打牌・ポン・カン・リーチ・和了・流局・東南戦の進み）と、キャラクターの打ち方を、2Dだけで遊べる形にする。
3. 3Dの卓と、座る・手を伸ばす動き。
4. しゃべる・写真・記録。
