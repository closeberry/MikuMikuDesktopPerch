# 麻雀（ミニゲーム）の設計

キャラクターと1対1で打つ、昔のゲームセンター風の2人打ち麻雀です。
キャラクターは本当に牌を読んで打つのではなく、**決めた確率で和了る**。ただし和了った手は、
場に見えている牌と必ず矛盾しないように、その場で組み立てる。

## 方針

- **サクサク打てる**：2人打ち、東風戦、キャラクターの番は1秒足らず。1回の対局が10分ほど。
- **別のウィンドウ**で遊ぶ（ダンジョンと同じ）。いつでも閉じてやめられる。
- キャラクターは、麻雀の間デスクトップから消え、同じモデルを卓の向こうに座らせて描く（PMXやモーションを二重に読み込まない）。
- 右クリックメニューの「麻雀を打つ」で、そのキャラクターと打つ。
- **プレイヤーの側は本物の麻雀**：ツモはでたらめな山から引き、和了り・役・点数は正しく計算する。
  ずるをするのはキャラクターの側だけ。
- **キャラクターと一緒にいること**を生かす：吹き出しで話す、和了ると喜ぶ、振り込むと悔しがる、写真に残す。

## ルール

- **2人打ち**：プレイヤーとキャラクターが向かい合う（自風は東と西）。牌は136枚（赤5を各1枚）。
- **チーはなし**。ポン・カン・リーチ・ロン・ツモはある。
- **東風戦**：東1局・東2局。親が和了るかテンパイで流局すると連荘（本場は1本300点）。
  持ち点は25000点で、どちらかが0点を下回ると、その場で終わる（飛び）。
- **点数**：ふつうの4人打ちの計算で出し、ツモでもロンでも、同じ点を相手が払う
  （ツモの点は、4人打ちで3人から受け取る合計）。
- **流局**：山がなくなったら。テンパイの人が、ノーテンの人から1000点もらう。
- **役**：一般的なもの（喰いタンあり、喰い下がりあり）。数え役満あり、ダブル役満なし、切り上げ満貫なし。
- 王牌は14枚。ドラ表示牌は1枚から、カンのたびに1枚増える。リーチで和了ると裏ドラ。

## プレイヤーの操作

- 手牌は画面の下に2Dで大きく並べる（いつも理牌済み。ツモった牌は右に少し離して置く）。
- クリックか←→とEnterで切る。
- ポン・カン・リーチ・ロン・ツモ・見送りは、できるときだけボタンが出る（キーはP、K、R、Enter、スペース）。
- **リーチ後はツモ切りを自動で**する（和了れる牌のときだけ止まる）。
- テンパイすると、待ち牌と残り枚数（自分から見えていない枚数）を出す。フリテンなら「フリテン」と出す。

## キャラクターの手：確率で和了る

### 見えない牌

全136枚から、次の牌を除いたものを**見えない牌**と呼ぶ。

- プレイヤーの手牌と、プレイヤーがこれまでに引いた牌
- 両者の河（捨て牌）、晒した牌（ポン・カン）
- ドラ表示牌

山とキャラクターの伏せた手牌は、どちらも見えない牌の中身なので、決めるまでは**中身を決めない**。

- **山**は「残り枚数」だけを持つ。だれかがツモるとき、その場で見えない牌から1枚を選ぶ
  （ゲームの最初に山を混ぜておくのと、結果は同じ）。ドラ表示牌と裏ドラも、めくるときに選ぶ。
- **キャラクターの手牌**は、伏せた牌の枚数だけを持つ（13枚。ポンするたびに3枚減る）。
- **キャラクターの捨て牌**は、切るときに見えない牌から選ぶ。
  序盤ほど字牌と端の牌（1・9）、終盤ほど真ん中の牌を選びやすくし、本物の打ち方らしく見せる。

### 和了るかを決める

- キャラクターの番ごと（ツモの直後）と、プレイヤーが切るたびに、和了るかを決める。
- 確率は巡目で上げていく（5巡目まではほとんど和了らず、10巡目を過ぎるとぐっと上がる）。
  1局あたりの和了率が、難しさ「やさしい」で約30%、「ふつう」で約40%、「ゲーセン」で約55%になるように合わせる。
- ロンにするかツモにするかは半々くらいにする。ロンは、切られた牌で手を組めたときだけ（下の「手を組む」）。
- プレイヤーがリーチしていると、キャラクターは少し和了りやすくする（押し返してくる感じ）。

### 手を組む

和了ると決めたら、その場で手を組む。

1. **点数の帯を選ぶ**：たとえば、安手（〜3900）65%、5200〜7700 20%、満貫 10%、跳満以上 4%、役満 1%。
2. **狙う役を選び、見えない牌から組む**：役ごとの組み方（断么九なら2〜8だけで、役牌なら字牌の刻子から、など）で、
   4面子1雀頭を見えない牌の中から作る。
   - ロンなら、和了牌はプレイヤーが切った牌に固定する。ツモなら、和了牌も見えない牌から選ぶ。
   - ポンしているときは、その面子を必ず入れる。
3. **確かめる**：組んだ手を、プレイヤーと同じ役・点数の計算に通す。役があって狙いの帯に入れば、それで和了る。
   **待ちのどれかがキャラクターの河にあるとき（フリテン）は、ロンに使わない**。
4. うまく組めなければ、何十回か組み直す。それでも駄目なら一つ下の帯にする。
   どの帯でも組めなければ、その番は和了らない。

これで、たとえば「中が河に2枚あるのに中を3枚持って和了る」ようなことは起きない（見えない牌に中は2枚しかない）。

### リーチとポン

- **リーチ**：キャラクターは、10%ほどの確率でリーチする（8巡目あたりから）。
  リーチした瞬間に、テンパイの手を見えない牌から組んで**確定**させる（その牌は見えない牌から外す）。
  - これより後は待ちが変わらないので、和了り方が変わる。
    - プレイヤーが待ち牌を切ったら、必ずロン。
    - ツモると決めた番には、見えない牌に待ち牌が残っていればそれをツモる。
    - そうでない番は、待ち牌以外をツモって、そのまま切る。
  - 待ち牌がもう見えない牌にないと、そのまま和了れないこともある（本物らしく）。
  - 裏ドラは、和了ったときに見えない牌からめくる。
- **ポン**：プレイヤーが役牌を切って、見えない牌にその牌が2枚以上あるとき、30%ほどでポンする（それ以外の牌はポンしない）。
  晒した3枚は見える牌になる。それより後に組む手には役牌の刻子が入るので、役は必ずある。

### 流局のとき

- キャラクターがテンパイかを確率で決める（巡目の和了率と同じくらい）。
- テンパイなら、和了るときと同じように見えない牌からテンパイの手を組んで見せる（役はなくてよい）。
- リーチしていれば、確定した手を見せる。

### なかよし度

なかよし度の段階（[docs/Bond.md](Bond.md)）が上がるほど、キャラクターの和了率を少しだけ下げる（段階×2%）。
冷たくても不利にはならない。

## 点数計算

プレイヤーの和了りとキャラクターの手の確かめの両方で使う、ゲームの中心の部品。画面から切り離して作り、既知の手でテストする。

- **和了形**：4面子1雀頭（すべての分け方を試す）、七対子、国士無双。
- **役**：分け方ごとに判定し、いちばん高い分け方を採る。
  リーチ・一発・海底・河底・嶺上開花・槍槓・ダブルリーチ・天和・地和は、局の状態から判定する。
- **符**：20符に、面前ロン10、ツモ2、面子・待ち・雀頭の符を足して10符単位に切り上げる
  （平和ツモは20符、七対子は25符、鳴いた平和形のロンは30符）。待ちが何通りにも取れるときは高い方。
  連風牌（親の東）の雀頭は4符。
- **点数**：基本点＝符×2^(翻＋2)。満貫〜役満で頭打ちにし、親は1.5倍、100点単位に切り上げる。
  役満が重なっても役満1つ分。ドラは役があるときだけ数える。
- **同じ部品で**：テンパイと待ち牌、リーチできるか（切るとテンパイになる牌）。フリテンは、待ち牌と河を比べて進行の側で見る。
- 部品は `src/Mahjong.cpp`。テストは `tests/MahjongHands.txt` に1行1つの手で書き、
  `MikuMikuDesktopPerch.exe --mahjong-test tests\MahjongHands.txt out.txt` で確かめる
  （out.txt の1行目に、確かめた数と合わなかった数。合わないものがあると終了コード1）。

## 卓と3D

- ウィンドウの上の方に、卓の向こうのキャラクターを少し見下ろすように3Dで描く。
  卓の上には、山、両者の河、キャラクターの伏せた手牌（背中）、晒した牌、ドラ表示牌。
  プレイヤーの手牌だけは下に2Dで大きく描く（3Dの大きさに関係なく読みやすいように）。
- キャラクターは椅子に座る。ウィンドウのふちに座る姿勢（Sit）を、椅子の座面をふちとして使う。
- **卓の大きさはモデルに合わせる**：座ったときの肩の高さから、卓の高さと奥行きを決める。
  カメラは卓とキャラクターが収まるように引く。

### 手を伸ばして取る（小さいモデルにも）

牌を指でつかむところは描かない。手を伸ばした瞬間に、牌が移ったように見せる。

- **ツモ**：山の方へ片腕を伸ばす（0.3秒）。手がいちばん伸びたところで山の牌が消え、伏せた手牌の右に1枚増える。手を戻す。
- **打牌**：手牌の前から河の方へ手を出し、同じ瞬間に河に牌が現れる（少し落ちて止まる）。
- **届かないとき**：腕の長さ（肩から手首までのボーンの長さ）で届く所までしか伸ばさない。
  ねんどろいどのような小さいモデルでは山まで届かないので、**取るふりをして、牌は光の粒と一緒にワープさせる**
  （山の牌が光って消え、手牌の所に光って現れる）。河に切るときも同じ。届くモデルでも同じ見せ方にそろえてよい。
- 腕の動きは GeneratedMotion に Reach として足す（docs/MotionRules.md に従う：ひじはローカルYだけ、手首は回さない）。
- **リーチ**：牌を横にして切り、点棒を卓に置く。**ポン**：「ポン！」と言って、プレイヤーの河から牌を取る（同じくワープ）。
- **和了**：「ロン！」「ツモ！」で、伏せた手牌を両手で前に倒して見せる。
  プレイヤーが和了ったとき・振り込まれたときは、驚く・ため息などの手ぶり（Surprised、Sigh）。
- 考えているふり（Think）は、ときどきだけにする（テンポを落とさない）。
- **テンポ**：キャラクターの番は全部で0.6〜0.9秒。設定で「早送り」にすると、手の動きを省いて牌だけ動かす。

## しゃべる麻雀

- キャラクターの言葉は、ダンジョンと同じく下の**吹き出し**に出る。声の設定があれば声も出る。
- リーチ・ポン・ロン・ツモの掛け声は、いつも決まったセリフで、すぐに出す。
- 和了った・振り込んだ・親になった・オーラス・対局の終わりなどで話す。LLMがあれば、そのときの点数や役を伝えて自分の言葉で話す。
- 和了ったときと役満のときは、自動でアルバムに写真を残す（Pキーでいつでも撮れる）。

## 記録

- キャラクターごとに `characters\<モデル名>-<番号>.mahjong.txt`（UTF-8の `キー=値`）。
  対局数、勝った数、和了った回数、いちばん高い和了り（役と点数）、出した役満。
- 対局が終わると、キャラクターが結果を話す。

## 作る順番

1. 点数計算（和了形・役・符・点数・テンパイ）と、そのテスト。
2. 見えない牌と、キャラクターの手を組む部分（たくさん組んで、場と矛盾しないか・狙った帯に入るかを確かめる）。
3. 局の進行（ツモ・打牌・ポン・カン・リーチ・和了・流局・東風戦の進み）を、2Dだけで遊べる形にする。
4. 3Dの卓と、座る・手を伸ばす動き。
5. しゃべる・写真・記録。
