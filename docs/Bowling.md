# ボウリング（ミニゲーム）の設計

キャラクターと1レーンを交代で使う、10フレームのボウリングです。ボウリング場のレーンを助走路の後ろから見て、あなたとキャラクターが1フレームずつ交代で投げます。

## 方針

- **ほかのミニゲームと同じ作り**：別のウィンドウで遊び、キャラクターはその間デスクトップから消えて、同じモデルがボウリング場に立つ。
  吹き出し・観戦・デスクトップに戻ってからのひと言は、卓球（`docs/TableTennis.md`）と同じ。
- 右クリックメニューの「ミニゲーム」→「ボウリングをする」で、そのキャラクターが相手になる。いつでも閉じてやめられる（途中のEscは、Yでやめる、Nで続ける）。
- **3D表示のみ**（3D表示が作れないときは、そう伝えて閉じる）。
- **あなたの側は球だけ**：体は描かない。キャラクターは自分の番に助走して、自分の腕で投げる。
- ボウリング場はコードで作る（レーン5本、ガター、ピンデッキとピット、ピンの上の飾り板、天井と壁の明かり、ボールリターン、スコア画面、後ろの席）。
  大きさはキャラクターの身長に合わせる：頭のボーンまでの高さを身長1.6 mの人のものとして、1 mの長さを決める（上半身の長さだけで決めると、脚の長いモデルでレーンが狭く見えた）。

## 操作

| 操作 | すること |
|---|---|
| マウスを左右に動かす | 立つ位置（球を投げる位置）を決める（あなたの番の間、カーソルはウィンドウから出ない） |
| 左ボタンを押したまま手前へ引き、前へ押し出して離す | 投げる。離す直前（0.09秒）のマウスの速さで球速、左右の向きで投げる向きが決まる |
| ホイール、←→、A・D | 回転（フック）の強さと向き（まっすぐ〜左へ曲がる・右へ曲がる） |
| 右クリック | 回転をまっすぐに戻す |
| 1〜3 | 相手の強さ（やさしい・ふつう・つよい。設定の `BowlingLevel` に残る） |
| P | 一時停止（クリックでも再開） |
| Esc | やめるか聞く（終わったあとは閉じる） |
| Enter | 終わったあと、もう一度 |
| 中ボタンのドラッグ | カメラを回す（Shift＋中ボタンで移動、Ctrl＋ホイールで寄る・離れる、中ボタンのダブルクリックかF1で戻す） |

- あなたの番では、いまの立ち位置と回転でまっすぐ投げたときの球の通り道が、レーンの上に薄く光って見える。
- 押し出しが遅すぎるとき（1秒に画面の高さの0.6倍より遅い）は投げずに、そう伝える。
- ほかのウィンドウに移ると一時停止する。

## ルールと点数（`src/Bowling.cpp`）

- 10フレーム。各フレームはあなたが先、キャラクターが後。ストライクは次の2投、スペアは次の1投を足す。10フレーム目はストライクかスペアで3投目。
- スコア表：X ストライク、/ スペア、- 0本、G ガター。
- 2投目は、1投目で立っているピンをそのまま残して投げる（倒れたピンはスイープで片付ける）。

## 球とピン（`src/Bowling.cpp`）

単位はメートル。x がレーンを横切る向き（投げる人の右が正）、y がレーンの長さ（ファウルライン 0、1番ピン 18.288）、z が上。

- **レーンの上の球**は自前で計算する：球は滑りながら回転に引かれて曲がり、やがて転がりになる（中身の詰まった球として、慣性モーメント 2/5 mr²）。
  手前 12.2 m はオイルで滑りやすく（摩擦 0.035）、その先は止まりやすい（0.17）。そのため球は奥で曲がる。転がり抵抗も少し。
  回転は、前へ転がる回転と、投げる向きへ傾けた軸の回転（フック）。端を越えるとガターに落ちて、ガターの底を転がる。
- **ピンデッキの手前（1番ピンの 0.62 m 手前）からは剛体**（Bullet）：球（6.8 kg）と10本のピン（1.53 kg、重心は底から 0.145 m、形はピンの輪郭を回した凸包）、デッキ、ガター、両側のキックバック、ピット、奥のクッション。1/600秒刻み。
  ピンが静かになって（または5.5秒たって）終わる。傾きが20°以内で、デッキの上に底をついて立っているピンが「立っている」。
- 球が当たった音、ピン同士の音などは、新しい接触の強さで拾う（倒れた本数で、小・中・大のピンの音を選ぶ）。

## キャラクターの投げ方

- **ねらい**（`Choose`）：10本立っていれば、右から（0.20 m）フックをかけて1番と3番の間（ポケット）へ。
  残りピンには、いちばん手前のピンを、残りのピンの側へ少し寄せてねらい、反対側から回転を弱めて少し速く投げる。
  ねらいの角度は、上の「レーンの上の球」の計算で、ピンの位置にちょうど来る向きを二分法で求める。
  そのうえで、強さ（1〜3）に応じて角度・球速・立ち位置をばらつかせる（`LevelStyle`）。隠れた手加減はない（強さはあなたが選ぶ）。
  強さごとの平均点（`--bowling-test`、最後に測ったもの）：やさしい 約125、ふつう 約160、つよい 約180〜190。
- **球の位置**：押し出しの間に手首の外側へ移り、そのあとは手首から横へ同じだけ離れたまま振れる（手のひらの向きに合わせると、振り下ろしで手が返るときに球が横へぶれた）。
  前後は、振る面の中で手のひらの前（振り子が前へ進む側）にあり、手が球のうしろから押す形になる（振り上げたいちばん上でも、球は手の前下）。
  助走路のどこに立つかは、実際に放したときの球の位置から次の投球のために覚え直す。
- **体**：自分の番になると、球を持つ手がねらいの位置に来るように助走路の後ろへ歩き（足は地面に置いたまま、体が離れたら1歩ずつ踏み出す）、
  球を胸の前で両手に持って構え（0.9秒）、4歩助走で投げる。
  - 1歩目：押し出し。2歩目：振り下ろし。3歩目：うしろへ振り上げる（いちばん上で腕は真下から68°うしろ）。4歩目：左足でスライドしながら振り下ろし、真下から8°前で放す（助走を始めて1.78秒）。
    放したあとは腕を前へ振り上げ（フォロースルー）、しばらくそのまま。
  - スライドでは膝を深く曲げ（脚の長さの0.31）、上体を前に40°倒す。右足はうしろへ引いて左へ交差させ、つま先を床につける。左腕は横へ広げてバランスを取る。
  - 腕は手首の行き先をMascotModel::Holdに渡す（スタイル4：スタイル3と同じだが、前腕を体の外へ押し出さない。押し出すと、うしろへ振った手がコートに引っかかって胸の前まで出てきたため）。
    スタイル4では手首はまっすぐ（手は前腕の延長）、手のひらは腕が前へ振れる向きを向く（ラケットの握りのように親指を上にはしない）。
    Holdが自分でつける前傾（18°〜）と肩の向き（手の方へ最大22°）は、その分を差し引いてHoldBodyに渡す。
  - 振り子の半径は腕の長さ（肩から手首）の0.97倍で、ひじはほぼ伸びたまま（振っている間 9〜11°）。スタイル4のHoldは腕の長さの0.995倍まで届く（ほかのスタイルは上腕と前腕の3/4まで）。
    フォロースルーの終わりでは、ひじは曲がる（参考にした人の動きでも同じ）。
  - 足：助走では左右の足首の間を股関節の間の0.55倍に寄せ（歩くときのように体の中心線の近くに着く）、立っているときは股関節の真下。モデルの休みの姿勢の足首の位置から決め、待機モーションの足の開きは使わない（加えると左右に開きすぎた）。
- 投げたあとはしばらく見送り、相手の番になると助走路の左の待つ場所へ戻る（次も自分の番なら構える場所へ）。
- 離れた場所へ移るとき（0.9 m 以上）は、デスクトップと同じ生成の歩き（腕も振る）で、進む向きを向いて歩く（歩き出しに向きを変える）。
  着く手前（0.3 m）で立つ姿勢に戻り、残りを小さく踏んでレーンの方を向き直す（前は球を持つ姿勢のまま足だけで動き、腕が止まったまま、手前へは後ろ歩きになっていた）。
- 助走の速さは区切りの間をなめらかにつなぎ、歩ごとに速さが急に変わらない。終わった一歩の足は、その足の次の一歩が始まるまでだけ着地点に置く（次の一歩の始めに、着く先へ飛んでいた）。
  左手が球から離れる・球に添うときは、0.35秒かけて移る。
- 待っている間、目はあなたの球を、転がっている間は球を追う。
- 試合が終わると、助走路の後ろに立ってカメラの方を向く（カメラは彼女の前から。結果の表示は彼女の頭より上）。

## しゃべる・反応

台詞は `res/bowling/lines.txt`（英語は `lines.en.txt`）。場面と「いつ」は [docs/GameLines.md](GameLines.md) の表のとおり。
吹き出しは、キャラクターが画面に映っていれば頭の横に、映っていないとき（カメラが球を追ってレーンの奥にあるときなど）は左下に、しっぽを下へ向けて出す。
ストライクを続けると「ダブル」、3回で画面に「ターキー！」。ガターや、ピンを残したときにも話す。終わったら、勝てば拍手、負ければ「あちゃー」。

## 確かめ方

- `--bowling-test out.txt [ゲーム数] [seed]`：点数の計算（パーフェクト300ほか）、レーンの上の球の曲がり方、ポケットなどへの投球で倒れる本数、強さごとのキャラクターの平均点。
- `--snapshot out.png 600 --bowling [段階]`：あなたの球は自動で投げる。段階 1 キャラクターのバックスイングのいちばん上、2 放す直前、3 フォロースルーで止める（カメラはキャラクターに向く）、4 あなたの球を引いたまま、5 構えたまま、6 吹き出しを出したまま、7 9フレームまで済ませた状態から（終わりの画面を見る）。
  報告の `her first approach` に、1投目の助走での球の横の位置。
  `--bowling-camera 縦,距離,横`（横 1.57 / -1.57 で左右から）、`--bowling-level 1-3`。報告の `bowling:` 行に、手首を送った先と実際の位置。

## これから

- 実際のマウスでの投げ心地（球速・向きの感度）は、遊んでもらって調整する。
- キャラクターが放すときの球の高さ（いまは床から0.5 mほど。実際はもっと低い）。
- 二人目以降のモデルでの見え方の確認。
