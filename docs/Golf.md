# ゴルフ

右クリックメニューの「ミニゲーム」→「ゴルフをする」で、別のウィンドウでそのキャラクターとストロークプレーをします。ホール数は「3ホール」（1〜3番）、「3ホール（ランダム）」（9ホールから3つを選んでランダムな順で）、「6ホール」（1〜6番）、「9ホール」（パー35）から選びます。3D表示でだけ遊べます。

## コース

コースは9ホールです。風の向きと強さはホールごとに変わります。地面に沿った距離（飛距離、ホールの長さ、ピンまで、ゲージの数字）はヤードで、高さはメートルで出ます。

| ホール | パー | 距離（フェアウェイに沿って） | 特徴 |
|---|---|---|---|
| 1 | 3 | 約165ヤード | 右手に池、グリーンのまわりにバンカー |
| 2 | 4 | 約390ヤード | ゆるい左ドッグレッグ、右に池 |
| 3 | 3 | 約170ヤード | グリーンを3つのバンカーが囲む |
| 4 | 5 | 約565ヤード | 右ドッグレッグ、約36 mの打ち上げ |
| 5 | 4 | 約405ヤード | 狭いフェアウェイ、グリーン右にバンカー |
| 6 | 4 | 約355ヤード | 約34 m登るミドル |
| 7 | 3 | 約190ヤード | グリーン右に池、少し打ち下ろし |
| 8 | 5 | 約580ヤード | S字、いったん約24 m下って登り返す |
| 9 | 4 | 約415ヤード | 広いアプローチと大きいグリーン |

最初のラウンドはコースのカップに、2ラウンド目からはグリーンの別の場所にピンが立ちます。ホールの始まりには、フェアウェイに沿ってホールを見渡します。ドッグレッグのホールでは、ティーからの狙いもフェアウェイの向きになります。クラブハウスは4種類（洋風、モダン、山荘風、南欧風）から、ラウンドごとに1つ選ばれ、ホールごとに決まった場所に建ちます。

コースのまわりの濃い緑の帯から外はOBで、その外側（クラブハウスのまわりを除く）は5種類の木の林になっています。クラブハウスの敷地もOBです。木の下の地面は暗くなっています。木の葉や枝に当たった球は勢いを失って落ち、幹に当たると跳ね返ります。フェアウェイには刈り込みの縞、グリーンには高低差が分かるよう薄い市松模様が入っています。池は透明感のある深い青緑で、上から見ると底に光の網目がゆらめき、低い角度からは空の色を帯びます。風で不規則にさざ波が立ち、波の小さな面が日の光をきらきらと返します（遠くの水面ほどなめらかに見えます）。球が落ちると水しぶきが上がって波紋が広がります。左上の風の矢印は画面から見た向きです。

## あなたのショット

- ←→で狙い（Shiftで細かく）、↑↓でクラブを選びます。黄色く淡く光って回る魔法陣は、そのクラブで100%打ったときに落ちるところです（ライの影響なし、風なし、打点は込み）。0キーか右クリックで、その輪を真上から見ます。そのあいだは中ボタンのドラッグで見る場所を動かせ、↑↓で狙いの向きに沿って動かせ、Shift＋↑↓で近づいたり離れたりでき、もう一度0キーか右クリック、またはSpaceで元の視点に戻ります。パターでは、平らなグリーンを100%で打ったときに止まるところに小さな魔法陣が出ます。グリーンの上では、カップまでのまっすぐな距離の強さで打ったときに転がりそうな道が、球から4 mまで点線で出ます（あくまで予測で、強さによっては外れます。遠いパットでは途中までしか出ません）。
- Ctrl＋矢印キーを押している間、球のどこを打つかが動きます（ゲージの右の球に赤い点で出ます）。Ctrl＋↑か↓だけを押し続けると、左右のずれは真ん中に戻っていきます。下を打つと高く上がって少し遠くへ飛び、止まりやすくなります。上を打つと低く飛んでよく転がります。左を打つと右へ、右を打つと左へ曲がります。
- Spaceかクリックでゲージが動き出し、もう一度押すと強さが決まります。押さずに戻ってきたら、打たずにやり直しです。ゲージの数字は、そのクラブで100%打ったときの平らな地面での飛距離で、強さはこの飛距離に比例します（50%でその半分の距離が飛びます）。ゲージの上の赤い旗は、カップまでのまっすぐな距離の位置です（高低差、風、ライは入れていません。どれだけ強弱をつけるかの目安にします）。
- 強さを決めるとマーカーが左へ戻ります。白い線のところで押すとまっすぐ、ピンクのところでは曲がり（早いと右、遅いと左）、ピンクを外すと大きくそれます。白い線の幅は、飛ぶクラブほど狭くなります。ラフやバンカーからは、長いクラブほどゲージが速く動きます（ラフはドライバーで2倍から9番アイアンで普段どおりまで、バンカーはその倍、ドライバーで4倍）。強さを決めたあと、2回目を押さずにマーカーが端まで行ったら、打たずにやり直しです。
- スピンショット：強さ50%以上で白い線のところで打ち、そのとき
  - 下打点で↓キーを押したままなら、バックスピン：3回目のバウンドでぴたりと止まり、少し戻ります。
  - 上打点で↑キーを押したままなら、トップスピン：止まりかけたところから、もう少し転がります。
- スペシャルゲージ（左上、2本までためられます）：パター以外で打つたびに増え、白い線のところで打つともっと（白で2回打つと1本分）、スピンショットならさらに増えます。打つ前にSキーでメニューを出し、↑↓とSpace・Enter（またはクリック）でブースト、メテオ、キャンセルから選びます。どちらもゲージ1本です。メニューでもう一度Sを押すと、スペシャルショットをやめます。白い線を外しても出ますが、まっすぐには飛びません。
  - ブーストショット：いつもより遠くへ飛びます。
  - メテオショット：どのクラブでも高く上がり、同じショットをふつうに打ったときの（転がりも入れた）距離の1.2倍ほど飛んで、落ちたところに止まります（坂でも転がりません）。飛んでいるあいだは炎を吹き、落ちると閃光、火柱、地面を走る光の輪、土くれと煙の大爆発が起きて、画面が揺れます。スピンショットと組み合わせると、止まったあとに戻ったり転がったりします。
  - キャラクターも、全力で打ってもピンに届かないときにブーストショットを使います。
- パターは、強さを決めたところで打ちます。最大の距離は、ピンまでの距離と上りの高さから決まります。
- ピンの上には空まで光の柱（ライトピラー）が立ち、まわりを光の粒が回りながら昇っていきます。柱にはピンまでの距離と高さの差が出ます。旗竿はなく、柱はホールの始まりからパターのときまでずっと立っています。
- 空中の球がライトピラーに触れると、柱に吸いこまれるように真下へ引き寄せられます。遅い球はそのままカップに入り（ライトフォール）、速い球は引っぱられても勢いでカップを越えていきます。速い球がピラーに引き下ろされてカップの先に落ちたとき、バックスピンがかかっていれば、球はカップへ向かって、カップを少し越えるところまで戻ります（入ることがあります）。
- 球が飛んだり転がったりしているあいだ、画面の上に打った所からの距離がヤードで出ます。
- 球の軌跡は、跳ねたり転がったりするあいだも含めて、球が速いほど明るく光ります。白のところで打ったショットは、軌跡がきらきら光ります。
- カップに入ると、ホールインワン、バーディー、パー、ボギーなどのスコアの名前が大きく出ます。
- カート道は硬く、球はあまり減速せずよく跳ねます。池は1打罰でその手前から、OBは1打罰で打ち直し。10打でギブアップです。
- ピンから遠い人が先に打ちます（ティーショットはあなたから）。
- Tabキーで操作の説明を出します。

## キャラクター

キャラクターは、球から魔法陣への線に直角に立ってアドレスし（長いクラブほど球から離れて立ちます）、バックスイング、トップ、ダウンスイング、インパクト、フィニッシュと振ってから球が飛びます。弱く打つときほど、バックスイングとフィニッシュは小さくなります。クラブは左手に握られて手首といっしょに動き、右手はその少し下を握ります。クラブは種類ごとに長さとライ角が違い（ドライバーがいちばん長く平ら）、ゴムのグリップ、細くなっていくシャフト（ウッドはカーボン）、ヘッド（アイアンはロフトのついたブレード、ウッドは黒い丸いヘッドに銀のフェース、パターは平たいブレード）がついています。球は、ヘッドが球のところに来たフレームで飛び出します。ダウンスイングでヘッドはだんだん速くなり、インパクトで球が飛び出す速さと同じになって、そこからフィニッシュへ向けてゆるみます。パターは肩を揺らしながら、腕とクラブをひとつの振り子にして、強さに合わせて前後に最大45°ずつ振ります。手首の形はアドレスのまま変わりません。クラブや狙い、強さは、風と傾きを入れて打ってみたときの、残りの打数がいちばん少なそうなものを選びます。ショットはいつも思いどおりとは限りません。あなたが打つ間は、球の横で見ています。

ナイスショット、ミス、池やOB、カップイン、勝ち負けで、キャラクターが吹き出しで話します（場面は [GameLines.md](GameLines.md)）。ラウンドが終わると、カメラは最終グリーンのそばに立つキャラクターを正面から映し、結果はその下に出ます。キャラクターは、勝てば笑顔でサムズアップ、負ければ額に手を当てて「あちゃー」と、ときどきくり返します（引き分けではしません）。観戦しているキャラクターもときどきひと言いい、デスクトップに戻ると感想をひと言いいます。

## やり込み

遊んだ記録は、キャラクターに関係なくあなたのものとして `%LOCALAPPDATA%\MikuMikuDesktopPerch\golf.progress.txt` に残ります。Cキーでアルバムを開くと、実績、記録、着せ替えが見られます。

- **その日のコンディション**：ラウンドごとに、晴れ、強風（風速6.5〜12.5 m/s）、雨（球が跳ねず、転がらず、止まりやすい。バンカーは変わらない）、夕暮れ（光が低く暖かい色に）、難しいピン（グリーンの端に近い所にピンが切られる）のどれかになります。左上のホールの表示に出ます。キャラクターの最初のひと言もその日に合わせます。
- **ホールのミッション**：ホールごとに1つ、パーに合ったお題（1打でグリーンに、1打目でピンから5ヤード以内、ティーショットをフェアウェイに、パーオン、バーディー以上、2パット以内、池にもOBにも入れない）が左上に出ます。達成すると★が1つ増えます。
- **ホールインワン**：1打目がカップに入るときは、入る直前にカメラがカップのそばへ下りて、球が転がりこむところを低い位置から映します。
- **実績**：ホールインワン、アルバトロス、イーグル、バーディー、チップイン、ライトフォール、スピンイン、メテオイーグル、ロングドライブ（280ヤード以上）、ロングパット（10ヤード以上）、ジャスト5連続、アンダーパー、ボギーなし、池もOBもなし、初勝利、段位、強風・雨で勝つ、夕暮れのラウンド、難ピンバーディー、ミッション全制覇の22個。取ると画面の上に知らせが出ます。
- **記録**：ホールごとのいちばん少ない打数、3・6・9ホールのラウンドのベストスコア、ラウンド数と勝ち数、★の数。
- **着せ替え**：実績で、ショットの軌跡の色（金、エメラルド、すみれ、虹）、魔法陣の模様（五芒星、花紋、歯車）、球の色（金、桜、空色、黒曜）、メテオの炎の色（蒼炎、紫炎、翠炎）が使えるようになります。アルバムで↑↓で種類を、←→で選びます。選んだものは次のショットから使われます。
- **キャラクターの段位**：キャラクターは段位1〜9（はじめは5）を持ち、あなたが勝つと1つ上がり、負けると1つ下がります。段位が高いほど上手に打ちます。

## 操作

| 操作 | 内容 |
|---|---|
| ←→ / ↑↓ | 狙い / クラブ |
| Ctrl＋矢印 | 打点 |
| 0・右クリック | 魔法陣を真上から見る（もう一度かSpaceで戻る。↑↓か中ボタンのドラッグで動かす、Shift＋↑↓で近づく・離れる） |
| S | スペシャルショットのメニュー（↑↓で選び、Space・Enterで決める。もう一度Sでやめる） |
| 強さ50%以上・白で、下打点＋↓ / 上打点＋↑ | バックスピン / トップスピン |
| Tab | 操作説明 |
| C | アルバム（実績、記録、着せ替え。↑↓で種類、←→で選ぶ。CかEscで閉じる） |
| Space・クリック | ショットのゲージ |
| 右ボタンか中ボタンのドラッグ、ホイール | カメラを回す、寄る・離れる（F1か右ダブルクリックで元に戻る） |
| Esc | やめる（Yでやめる、Nで続ける）。終わったあとは閉じる |
| Enter | 終わったあと、新しいコースでもう一度 |

ほかのウィンドウを使っていたときのクリックは、ゴルフのウィンドウを前に出すだけで、ショットやカメラには使われません。

## 確かめ方

- `--golf-test out.txt [ホール数] [シード]`：クラブごとの飛距離と転がり、スピンとスペシャルのショット、作ったホールの確認（ティーとピンの位置）、キャラクターがそれぞれのホールを回った打数（1番から順に、10ホール目からはピンを動かして）。
- `--golf-hole n`（`--snapshot` と）：ラウンドをn番ホールから始めます。
- `--golf-round 3|3r|6|9`（`--snapshot` と）：ラウンドのホール数（r はランダムに選ぶ）。
- `--golf-ace`（`--snapshot` と）：風を0にして、あなたの最初のティーショットを、ライトピラーで落としてバックスピンで入るメテオに探して打ちます（`.txt` に `ace search`）。ホールインワンのカメラを見るのに使います。
- `--golf-weather 0|1|2|3|4`（`--snapshot` と）：その日のコンディションを晴れ、強風、雨、夕暮れ、難しいピンにします。
- `--golf-progress <file>`（`--snapshot` と）：記録をそのファイルから読み、そこへ書きます（ないと診断の実行では記録を残しません）。
- `--snapshot out.png 260 --golf-gauge 0,0,album`：アルバムを開いて止めます。
- `--golf-special 1|2`（`--snapshot` と）：自動で打つあなたのショットを、ブースト（1）かメテオ（2）にします。`.txt` には、キャラクターのクラブごとの長さと球の位置、打った瞬間のヘッドと球の位置も出ます。
- `--snapshot out.png 900 --golf [--golf-seed n]`：あなたの側も自動で打ちます。`.txt` の `golf` 行に、打ったショットと結果。
- `--snapshot out.png 260 --golf-gauge 強さ,位置[,help,overhead,putter,spot,menu,green]`：あなたの最初のショットのゲージをその状態で止めます（強さ0は強さを選んでいる途中）。menu はスペシャルショットのメニューを開き、green はあなたの球をピンの7 m手前のグリーンに置いてパットの予測線を出します。
- `--snapshot out.png 150 --golf-swing <段階> [向き [強さ [putter]]]`：キャラクターがスイングのその段階（0 アドレス、0.5 バックスイング、1 トップ、1.5 ダウンスイング、2 インパクト、3 フィニッシュ）で止まります。向きは0で正面、1.57で目標側から。強さは0〜1（既定は1）、putter でパターの振り方になります。
- `--snapshot out.png 60 --golf-swing-vmd <out.vmd> [強さ [putter]]`：iniの最初のキャラクターのスイングを、ゲームと同じ速さでVMDに書き出します（30fps、全フレームにキー、7番アイアン（パターは10 m）の強さに合わせた速さ。アドレス約0.5秒、インパクトがちょうどフレームに乗るように調整、フィニッシュで1秒。動くボーンだけ）。レポートにヘッドのフレームごとの速さが出ます。
- `--golf-bones`（上の2つと組み合わせて）：キャラクターを隠して骨格だけを描きます（左半身は青、右半身はオレンジ）。服やマントに隠れた腕の形を確かめるのに使います。
