# ゴルフ（試作）

右クリックメニューの「ミニゲーム」→「ゴルフをする」で、別のウィンドウでそのキャラクターと3ホールのストロークプレーをします。3D表示でだけ遊べます。

## コース

1ホール（パー3、約130 m）のコースを3回まわります。1番はコースのカップに、2番と3番はグリーンの別の場所にピンが立ち、風の向きと強さはホールごとに変わります。ティーの先にフェアウェイ、右手に池、グリーンのまわりとフェアウェイ脇にバンカー、左手にカート道があり、グリーンの奥の高台にクラブハウスが建っています。クラブハウスは4種類（洋風、モダン、山荘風、南欧風）から、ラウンドごとに1つ選ばれます。コースの外とクラブハウスの敷地はOBです。左上の風の矢印は画面から見た向きです。

## あなたのショット

- ←→で狙い（Shiftで細かく）、↑↓でクラブを選びます。黄色い輪は、そのクラブで100%打ったときに落ちるところ（風なし）です。
- Spaceかクリックを3回：1回目でゲージが動き出し、2回目で強さが決まり、戻ってくるマーカーが白い線に来たところで3回目。早いと右へ、遅いと左へ曲がります。左端まで行くと大きく曲がります。
- パターは、ピンまでの距離から最大の距離（3〜60 m）が決まり、ゲージの強さがその割合です。上り・下りの高さも表示されます。
- 池は1打罰でその手前から、OBは1打罰で打ち直し。10打でギブアップです。
- ピンから遠い人が先に打ちます（ティーショットはあなたから）。

## キャラクター

キャラクターは自分の球のところでアドレスし、バックスイング、ダウンスイング、フォローまで振ってから球が飛びます。クラブや狙い、強さは、風と傾きを入れて打ってみたときの、残りの打数がいちばん少なそうなものを選びます。ショットはいつも思いどおりとは限りません。あなたが打つ間は、球の横で見ています。

ナイスショット、ミス、池やOB、カップイン、勝ち負けで、キャラクターが吹き出しで話します（場面は [GameLines.md](GameLines.md)）。観戦しているキャラクターもときどきひと言いい、デスクトップに戻ると感想をひと言いいます。

## 操作

| 操作 | 内容 |
|---|---|
| ←→ / ↑↓ | 狙い / クラブ |
| Space・クリック | ショットのゲージ |
| 右ボタンのドラッグ、ホイール | カメラを回す、寄る・離れる（F1か右ダブルクリックで元に戻る） |
| Esc | やめる（Yでやめる、Nで続ける）。終わったあとは閉じる |
| Enter | 終わったあと、新しいコースでもう一度 |

## 確かめ方

- `--golf-test out.txt [ホール数] [シード]`：クラブごとの飛距離と転がり、作ったホールの確認（ティーとピンの位置）、キャラクターがそれぞれのホールを回った打数。
- `--snapshot out.png 900 --golf [--golf-seed n]`：あなたの側も自動で打ちます。`.txt` の `golf` 行に、打ったショットと結果。
- `--snapshot out.png 150 --golf-swing <段階> [向き]`：キャラクターがスイングのその段階（0 アドレス、1 トップ、2 インパクト、3 フィニッシュ）で止まります。向きは0で正面、1.57で目標側から。
