# ウィンドウの上のモーションの作り方

[English](WindowMotions.en.md)

キャラクターがウィンドウの上端に乗ったとき（「アクティブウィンドウに乗る」がオンのとき）、アプリが作る「座る」「ぶら下がる」のほかに、VMDのモーションで休んだり、ウィンドウの上を移動したりできます。

- **組み込み**：提供していただいたモーションをexeに入れて、みなさんが使えるようにします（下の「提供していただくとき」）
- **自分で追加**：右クリックメニューの「モーション」→「ウィンドウの上のモーションを開く...」で、手元のVMDを選びます（複数選べます。キャラクターごとに覚えます）

乗るたびに、使えるもの（組み込み・自分で追加したもの・アプリの「座る」「ぶら下がる」）の中から1つを選んで、ずっと繰り返して再生します。移動するモーションがあれば、ときどき（20〜60秒ごと）それで横へ移動し、着いたら元の休み方に戻ります。どれを使うかは、設定の「しぐさを選ぶ...」で選べます（組み込みのものと、アプリの「座る」「ぶら下がる」。キャラクターごとに別の選び方にもできます）。

## 作り方の決まり

**床（高さ0）を、ウィンドウの上端として作ってください。** 床より下に出た部分は、ウィンドウの前に垂れて見えます（腰かけて脚を下ろすなど）。

- **正面を向いて**作ります（MMDの初期の向き。カメラの方が前です）
- **繰り返し（ループ）**で再生します。最初と最後のフレームを同じ姿勢にして、つなぎ目で止まったり跳んだりしないようにしてください
- **全ての親は動かさないでください。** 体の上下はセンターかグルーブで動かします
- 長さに決まりはありません（休むものは2〜10秒くらいが目安です）
- 表情（モーフ）は使われません。まばたきや口の動きはアプリが付けます
- 髪やスカートは物理演算で動くので、キーを打たなくてかまいません（打ってあっても使いません）

### ウィンドウの前か、後ろか

アプリが動きを見て決めます。

- **体を、身長の6割ほどより深く下げているもの**（センターとグルーブで下げた量の平均）は、ウィンドウの**後ろ**に描きます。ウィンドウの縁に手をかけてぶら下がる、縁から顔だけ出す、など
- それ以外は、ウィンドウの**前**に描きます。腰かける、寝そべる、ひざを抱える、頬杖をつく、など

### その場で休むか、移動するか

センターが、最初のフレームと最後のフレームで離れた所にあるもの（身長の1割ほど以上）は、**移動するモーション**として使います。1ループで進んだ分だけ、キャラクターが本当に進みます（手やひざが床に着いたまま滑らないように、アプリはモーションの進み方どおりに動かします）。

- **前へ進むもの**（センターがZ方向に動く。四つんばいで進む、など）：カメラの方（-Z）へ進むように作ってください。アプリが、歩くときと同じように横を向かせて、左右へ進ませます
- **横へ進むもの**（センターがX方向に動く。正面を向いたままお尻をずらして進む、など）：右左どちらに進むように作ってもかまいません。反対へ進むときは、アプリが左右を入れ替えて（鏡に映したように）再生します
- 足IKも、センターと一緒に進めてください（床に着いた足は、その場に残るように）
- ウィンドウの後ろのもの（ぶら下がったまま手で伝って進む、など）も作れます。移動は、休んでいたのと同じ側（前か後ろ）のものだけが選ばれます

## 提供していただくとき

GitHub の issue に、VMDファイルと、クレジット（お名前の表記）を添えてください。いただいたモーションは、作成に使ったモデル独自のボーン（髪・スカートなど）とモーフを除き、つなぎ目と動きをなめらかにして組み込みます。

## 確かめ方

自分で追加したものがどう扱われたか（前か後ろか、休むか移動するか）は、追加したときにログ（`%LOCALAPPDATA%\MikuMikuDesktopPerch\log.txt`）に書かれます。
