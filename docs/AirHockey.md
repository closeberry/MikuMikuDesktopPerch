# エアホッケー（ミニゲーム）の設計

キャラクター1人か2人を相手に、台の端と端で打ち合うエアホッケーです。
キャラクターは立ってマレットを持ち、腕を伸ばしてパックを打ち返す。

## 方針

- **すぐ遊べて、すぐ終わる**：7点先取（1回5分ほど）。いつでも閉じてやめられる。
- **別のウィンドウ**で遊ぶ（ダンジョン・麻雀と同じ）。相手のキャラクターは、遊ぶ間デスクトップから消え、
  同じモデルを台の向こうに立たせて描く（PMXやモーションを二重に読み込まない）。
- 右クリックメニューの「エアホッケーをする」で、そのキャラクターと遊ぶ。ほかのキャラクターがいれば、
  2人目を選んで2人を相手にもできる（2人は同じ側に並ぶ）。
- **本物の物理で打ち合う**：パックは壁で跳ね返り、マレットの速さで強く飛ぶ。キャラクターは、見えている
  パックの動きから読んで打つ（先の乱数やプレイヤーの操作は見ない）。
- **キャラクターと一緒にいること**を生かす：ゴールで喜ぶ・悔しがる、吹き出しで話す、写真に残す。
- 手の動きは**MMDのボーン追従とIK**の考え方で作る（下の「マレットを持つ」）。小さいモデル（ねんどろいどなど）でも破綻しない。
- 衣装や髪は台の剛体に当たり、体は共通の**めり込み判定**で台の手前に止まる（下の「めり込み判定」。ほかのミニゲームでも使う）。

## いまの段階

台の物理・マウス操作・相手の打ち方（`src/AirHockey.cpp` の Game と Brain）と、3Dの台でキャラクターがマレットを持って
打つところまで（`src/AirHockeyWindow.cpp`）。右クリックメニューの「エアホッケーをする」で、キャラクターはデスクトップから
消え、ウィンドウの台の向こうの端に立つ。3Dで描けないときは、台を上から見た2Dのウィンドウ（キャラクターは名前だけ）。
しゃべる・反応・観戦・戻ってからの感想も（下の「反応と手ぶり」「しゃべる・写真・記録」）。音・記録・写真・2人の相手はこれから。

- 3Dの台：上半身（下半身から頭まで）の2倍を台の1単位にする（幅が上半身の2倍、長さが3.6倍。身長1.6mの人に幅1.5m・長さ2.7m
  ほどで、卓球台より少し大きい。片方の端に2人並べる）。天板の高さは腰の高さの0.9倍。キャラクターは自分の端から上半身の
  0.34倍下がって立つ（太ももが台に当たらない）。白い天板、青いふち（ゴールの口で切れ、下に黒い溝）、中央線・中央の円・
  ゴールの半円、脚、床と壁の部屋。パックとマレットは円柱（マレットはつまみ付き）。
- カメラ：あなたの端の後ろの斜め上から、台と向こうのキャラクターを見下ろす（麻雀と同じ考え方。はじめの視点で、
  あなたのゴールも画面の下に入る）。右ボタンのドラッグで回り、
  中ボタン（かShift＋右ボタン）のドラッグで動き、ホイールで寄る・離れる。右ボタンのダブルクリックかF1で元に戻る。
  左ボタンではカメラは動かない。右ボタンでドラッグしている間は、マレットは止まり、カーソルも放す。
- マウス：カーソルの下の天板の点（カメラからの線と天板の交わるところ）へ、あなたのマレットが付いてくる。遊んでいる間、
  カーソルはあなたの側（マレットの真ん中が行けるところ）を画面に写した四角から出さない。
- 持つ動き：下の「マレットを持つ」のとおり。`--snapshot out.png 450 --airhockey` で、あなたの側を自動で打たせて撮り、
  `.txt` の `airhockey: 3D` の行に、台の大きさ・手の届く範囲・手とマレットのずれ・手の震え（`shake`、毎フレームの手の動きの
  変わり方の平均。上半身の長さを1として）を書く。`--airhockey-camera pitch,distance,yaw` でカメラを向けて撮れる。

- 台の単位：幅1、長さ1.8。パックとマレットの大きさは4段階から選ぶ（5〜8キー、いつでも。設定の `AirHockeyPieceSize` に残る）：
  本物くらい（パックの半径0.035、マレットの半径0.06、ゴールの口0.34）・少し大きい（1.25倍）・大きい（1.5倍、はじめ）・
  とても大きい（1.75倍）。ゴールの口は大きさとともに広がる（0.34+0.22×(倍率−1)。大きなマレットはゴールの前にいるだけで
  ほとんど防いでしまう）。マレットの持ち手は低く、てっぺんは半径の0.8倍の高さ。打ち合いの途中で変えると、パックはその側に
  置き直す（大きくなったマレットや壁に重ならないように）。
- 速さ：パックの最高の速さは4段階から選ぶ（1〜4キー、いつでも。設定の `AirHockeyPuckSpeed` に残る）：
  ゆっくり2.0・ふつう2.6（はじめ）・はやい3.2・とてもはやい4.0（1秒に台の長さの2倍あまり）。
  あなたのマレットは7.0まで（マウスにほぼそのまま付いてくる）。
  キャラクターのマレットは3.4までで、加速が40（腕で動かすように、動き出しと止まりにかかる）。
- 強さの目安：`--airhockey-sim` の「あなたの側」は、人のように0.25秒遅れて見るがマウスのように速く動く考えで、
  キャラクターはこれに60回に2〜8回ほどしか勝てない（ゆっくり2回、ふつう4回、はやい・とてもはやい8回。その考えは読みと
  狙いが正確なので、人より強い）。1対局は、ふつうで5分ほど、とてもはやいで2分ほど。
  実際に遊んで、強さを決める。

## ルール

- 台は長方形で、両端の真ん中にゴールがある。台の中ほどに中央線。
- 自分の側（中央線の手前）でだけマレットを動かせる。キャラクターも同じ。
- パックがゴールに入ると1点。入れられた側の手前にパックが出て、そちらから始める（最初はプレイヤーから）。
- 7点先に取った方の勝ち。
- パックがキャラクターの側で止まったまま（4秒ほとんど動かない）なら、プレイヤーの手前に置き直す（ゴールとは数えず、
  「ゴール」とも出さない）。プレイヤーの側では、いくら止めておいてもよい（自分の番）。

## プレイヤーの操作

- マウスでマレットを動かす。カーソルのある台の上の点（自分の側に収める）へ、マレットが少し遅れて付いてくる
  （速さに上限があり、壁とゴールの口と中央線は越えない）。速く振れば強く打てる。
- ウィンドウの中ではカーソルを隠し、マレットそのものをカーソル代わりにする。
- 遊んでいる間は、カーソルそのものを自分の側（マレットの真ん中が行けるところ）から出さない（`ClipCursor`）。
  マウスを中央線の向こうへ動かしすぎても、戻さずにすぐマレットを動かせる。一時停止・やめるかの問い・終わり、
  ウィンドウから離れたとき・動かしたとき・閉じたときは放す。
- Spaceで一時停止、Escでやめる（途中のEscは、Yでやめる・Nで続ける）。終わると結果を出し、Enterでもう一度、Escで閉じる。
- 1〜4キーで、パックの最高の速さを選ぶ（ゆっくり・ふつう・はやい・とてもはやい）。選ぶと少しの間、台の真ん中に出る。
  右上の「パック：ふつう（1〜4キー）」がいまの速さ。次に開いたときも同じ速さ。
- 5〜8キーで、パックとマレットの大きさを選ぶ（本物くらい・少し大きい・大きい・とても大きい）。同じく少しの間、台の真ん中に
  出て、右上の「大きさ：大きい（5〜8キー）」がいまの大きさ。
- カメラはプレイヤーの側のゴールの後ろから、台と向こうのキャラクターを斜めに見下ろす。麻雀と同じように、
  右ボタンのドラッグとホイールで動かせ、F1で元に戻る（左ボタンはマレットに使うので回さない）。

## 物理（パックとマレット）

- 台の上の2Dで計算する（高さは見た目だけ）。パックもマレットも円。
- 1フレームを細かく分けて（パックとマレットが1回にパックの半径の0.4より動かないように。64回まで）、すり抜けないようにする。
- パックと壁：反発係数0.9。台の空気で、1秒に12%ほど減速する（止まりきらない程度）。ゴールの口の両端（柱）でも跳ね返る。
  パックが端の線を半径の分だけ越えきったらゴール。
- パックとマレット：マレットは重い（パックに押し戻されない）。動く壁に当たったように跳ね返り（反発係数0.85）、
  マレットの速さがそのまま乗る。パックの速さには上限を付ける（目で追える速さまで）。
  壁とマレットに挟まれたら、パックは台に残り、マレットの方がよける。
- サーブ：ゴールのあと、入れられた側の手前にパックを置き、1秒たってから打てる（その間マレットはパックに触れない）。
- マレットの速さは、前のフレームからどれだけ動いたかで出す。キャラクターのマレットも同じ（手の位置から出すので）。
- 音：パックが壁に当たる「カン」、マレットで打つ「コッ」（強さで音量と高さを変える）、ゴールに落ちる「ガコン」、
  エアの小さな「シュー」。麻雀の打牌の音と同じく、プログラムで作る（`src/MahjongSound.cpp` の作り方を使う）。

## 台と3D

- 麻雀と同じ描き方で、ウィンドウ全体に台・キャラクター・部屋を3Dで描く。点数と残り時間は2Dで重ねる。
  3Dで描けないときは、台とマレットとパックを上から見た2Dで描き、キャラクターの顔を上に出す。
- **台の大きさはモデルに合わせる**：台の高さは、立ったときの腰（下半身のボーン）の少し下。台の幅と長さは
  キャラクターの腕の長さ（`GeneratedMotion` の rig の armReach）から決め、向こうの側の大部分に手が届くようにする。
  2人のときは、幅を1.6倍ほどにする。
- 台は白い天板に、ふちの低い壁、ゴールの口、中央線と円の線。脚は床まで。まわりは明るい部屋（ゲームセンターでなく、
  家の遊び部屋くらい）。天板の上に小さな光の粒（エアの穴）を並べる。
- キャラクターは、横から歩いてきて台の端に立ち、マレットを取る（マレットは台の上に置いてあり、手を伸ばすと手に収まる）。
  終わるとマレットを置いて、歩いて去る。

## マレットを持つ（ボーン追従とIK）

腕の動きは、MMDでマイクを手に持たせる仕組み（ボーン追従）と、手首を引っ張るとひじ・腕・肩が付いてくるIKで作る。
どちらもこのプロジェクトにある。

- **IK**：`GeneratedMotion::ReachArm`（手首の位置を決めると、ひじがpoleの向きに曲がり、肩が付いてくる2ボーンIK。
  肩の付き方は MotionTraceEditor と同じ `ShoulderTurn`）。
- **ボーン追従**：ダンジョンの剣と同じく、拳のつかみ（`MascotModel::Grip`）からマレットを描く。

流れ（毎フレーム）：

1. キャラクターの考え（下の「キャラクターの打ち方」）が、台の上のマレットの行き先を決める。
2. その真上の**決まった高さ**（台の上、マレットのつまみを握る高さ）に、`ReachArm` で手首を置く。
   手は高さを変えず、水平にだけ動く（台の上でマレットを滑らせているように見える）。ひじは横やや下へ逃がす。
3. 描いた姿勢の拳のつかみの真下を、**マレットの位置**にする（物理もこの位置を使う）。マレットはいつも手の中にある。
4. 腕だけで届かないところは、上半身を前に傾け（届かない分の半分まで、15°まで）、センターで横に一歩ずつ動いて補う
   （台の端に沿って、受け持ちの範囲の中で）。それでも届かなければ、手の届く端で止まる。
5. 空いた手は台のふちに軽く置く（左右は、マレットを持つ手の反対）。

- この「持ち続ける」動きは、`Reach`（伸ばして戻る短い動き）とは別に、`GeneratedMotion` に新しく足す
  （例：`Hold(side, point)` を毎フレーム与え、`Release` で放す）。持ち始めと放すときは、ゆるやかに入り・抜ける（0.4秒ほど）。
- 手首の目標には、前のフレームから動ける距離に上限を付ける（腕が一瞬で飛ばないように。キャラクターの反応の速さにもなる）。
- 持つ手は右（左利きの設定はなし）。2人のときは、左に立つ人は左手、右に立つ人は右手（外側の手）で持つ。
- `ReachArm` の `clear` で、マレットが体の正面に来ても前腕を体の前に保つ。
- 手の指は握る形（`CurlFingers`）。
- 作ったもの（`GeneratedMotion::Hold`、`AirHockeyWindow.cpp` の `TickAirHockeyWindow`）：
  - **マレットは手の子**：毎フレーム、いまの姿勢の手のつかみ（`Grip`）の真下に、キャラクターのマレットを置く
    （`Game::HoldMallet`。そのフレームの物理の中で、前の位置からそこへまっすぐ動き、その速さでパックを打つ）。
    マレットはいつも手の中にある。
  - **手は必要なときだけ動く**：キャラクターの考え（Brain）の行き先は、前の行き先から0.06（台の単位）より動いたときだけ
    変える。手はその行き先へ、腕で動かすように（速さ3.4まで、加速40）向かい、着けば止まる。手首とつかみのずれは、手が
    止まっている間に、大きくずれたときだけ（持ち始めの3秒は0.02×上半身、そのあとは0.08×上半身より）、ゆっくり（0.5秒ほどで）
    覚える（動いている手は目標に遅れるので、そのときに覚えると振れる。小さな直しも手を動かすのでしない）。
  - つかみは、つまみの上に手の厚みの半分（0.045×上半身）浮かせる（つまみが手のひらを突き抜けないように）。
  - めり込みのストップは、ゆとりの2倍の内では腕も前かがみも止めたままにし、はっきり離れてから戻す（台のふちで前かがみが
    浅くなったり深くなったりをくり返し、上半身ごと手が細かく揺れていた）。キャラクターは自分の端から上半身の0.4倍下がって立つ。横への動きも、0.08×上半身より離れたときだけ。持っている間、上半身は前かがみだけにして、
    待機モーションの揺れを手に伝えない。
  - 腕の姿勢は、作るたびに0.07秒かけて新しい姿勢へなめらかに移す。
  - `shake`：手を止めておくはずのフレームでの手の動きの変わり方の平均（上半身の長さを1として）。0.004ほど。
  - いつも腰から18°前かがみ（遠い点へはさらに35°まで）。ひじは横やや下、手のひらを下に、指は軽く曲げる。
  - 手が届かないところへは行かない：開くときに、まっすぐ前・左・右へ手を伸ばして届く範囲を測り（`MeasureHer`）、
    キャラクターの考えのマレットの行き先をその中に収める。
  - マレットの横の位置に合わせて、体ごと少し横へ動く（上半身の0.3倍まで。足の運びはまだない）。
  - 空いた手はまだ下ろしたまま（台のふちに置くのはこれから）。

## 台の剛体（衣装・髪が台にめり込まない）

- 台（天板とふち）と同じ形の、動かない箱の剛体を、キャラクターの物理に足す（モデルごとの Bullet の世界に、そのモデルの座標で）。
  いまは台の本体（天板まで、ふちの外まで）の箱1つ。低いふちは入れない（手を伸ばすと前腕がその上を通り、ストップがかかり続けて
  腕が引っ込んでしまったため）。
  2人のときは、それぞれの物理に足す。
- 衝突グループは**無視して全部と当たる**（床と同じ。`third_party/PMXLoader.ixx` の `MMDFilterCallback` の `m_nonFilterProxy`）。
  モデルの作者は床をグループ16として扱っていることが多いが、どちらでも当たるようにする。
- 剛体が台の中にある状態で当たりを入れると弾き飛ばされるので、台の前に立ち止まってから入れる。そのとき台の中に
  物理の剛体があれば、床と同じく、なめらかなリセット（`BeginPhysicsReset`）のあとで入れる。
- 骨に付いて動く剛体（物理演算でないもの）は、動かない台と当たっても押し返されない。体のめり込みは次の判定で防ぐ。
- 前に乗り出したとき、前に垂れた髪やリボンが台の上に乗って止まる。

## めり込み判定（共通処理）

モーションで体が台に入らないよう決めておくのは難しいので、描いた姿勢で確かめて、それより先へ行かせない。
エアホッケーだけでなく、麻雀の卓や、これからのミニゲームでも使う（`MascotModel` に置く）。

### 固いもの（ソリッド）の登録

- ミニゲームが、台などを**箱の並び**（真ん中・半分の大きさ・向きのクォータニオン。モデルの座標）として渡す
  （`MascotModel::SetSolids`。空で消える）。キャラクターに対して動くときは、そのたびに渡し直す
  （麻雀では毎フレーム）。箱の数が変わると、物理の剛体と下の「止める」を作り直す。渡した箱は、
  - 物理の動かない剛体になり（衣装・髪が当たる。上の「台の剛体」。全部のグループと当たる）、
  - めり込み判定にも使われる（体が当たる）。
- 剛体が当たり始める時期（中に物理の剛体があれば待ち、1.5秒たってもあれば、なめらかなリセットのあとで当てる）も、
  この共通処理が受け持つ。
- ミニゲームを閉じるときに、空にして消す。

### 判定する頂点

- 初めてソリッドが渡されたときに一度だけ、**物理ボーンのウェイトが乗っていない頂点**を集める（ウェイトのあるボーンが
  どれも物理演算でなく、物理演算のボーンの下にもないもの）。物理の頂点（スカート・髪など）は剛体の方で当たるので数えない。
- モデルの高さの1.2%の格子で、1つの升目・1つの部位につき1点に間引く（3000点ほど）。それぞれ、ウェイトのあるボーンと重み、
  部位（左右の手・前腕・上腕、胴、脚、頭）を覚えておく。部位は、いちばん重いボーンがどの鎖の下にあるかで決める
  （手首・ひじ・腕・頭・下半身か足。どれでもなければ胴）。

### 毎回の判定

- 姿勢と物理を解いたあと（`MascotModel::Update` の終わり）、ボーンの行列からその頂点の位置をウェイトどおりに出す
  （BDEF。SDEFはBDEF2として扱う）。モーフは数えない。
- 各箱について、中にあればいちばん近い面までの深さ、外にあれば箱までの距離（負の深さ）を出す。
- 結果は、部位ごとのいちばん深い点（深さ、その点、押し出す向き＝いちばん近い面の外向き。モデルの座標）
  （`MascotModel::Penetrations`）。
- ゆとり（`solidMargin`）はモデルの高さの1.2%。深さがゆとりより浅いところまで来たら（深さ > −ゆとり）、入ったとみなす。
- 重さ：3000点ほど×ボーン4本×箱の数。ソリッドがあるときだけ計算する。

### それ以上先へ行かない

- **腕**（`GeneratedMotion::StopArm`）：その腕（手・前腕・上腕のいちばん深いところ）が入ったら、押し出す向きを
  腕の上のボーン（肩の親）の元の向きに直して渡す。`ReachArm` はその向きの半空間を覚えておき（片腕に3つまで）、
  それからは手首の目標をその外に押し戻す（それより先へ行かない）。
  - 入った深さのぶん半空間を外へずらす。手首を動かしても前腕は少ししか動かないので、出るまで毎回ずらす。
  - 速さを見て1フレーム先を読む（今の深さ＋前の回からの近づき方）。止まるのが遅れて入ることはない。
  - 半空間は、その回の動きが手首を置きたい所から、その向きに脚の長さの0.4倍より先へはずらさない（前腕や上腕が入ったままだと、
    手首をずらし続けて腕が折りたたまれてしまうため）。
  - 押し戻されている間に離れていれば、半空間を少しずつ（脚の長さの25%／秒）戻す。ほかの姿勢で手を余計に離さないように。
    戻しすぎればまた止まる（ゆとりの中なので見た目にはめり込まない）。
  - `ReachArm` で動かす腕は全部これに従う：麻雀で手を伸ばす動き、座っての手ぶり（考える・拍手・頬・あちゃ～）、
    立っての手ぶり、これからのマレットを持つ動き。待機のVMDや組み込みのクリップの腕は止められない（判定だけ）。
- **体と頭**（`GeneratedMotion::StopLean`）：入ったら、Reach の前かがみを今より2°浅くまでに抑え、離れれば1秒に10°ずつ戻す。
- **脚**：判定だけ（センターの横移動はエアホッケーで足す）。
- ソリッドが変わると、半空間と前かがみの上限は消える（`ClearStops`）。

### 確かめ方

- スナップショットの `.txt` に `penetration:` の行：箱と頂点の数、ゆとり、剛体が当たっているか、部位ごとのいちばん深いところ
  （ソリッドを渡してから。かっこ内は最後の回）と、腕・前かがみを止めた回数。
- `--no-solid-stops`：判定はするが、何も止めない（比べる用）。
- 麻雀で：`--snapshot out.png 170 --mahjong 12 --mahjong-reach far --mahjong-solid-lift 0.45`。手を牌まで伸ばし（`far`。
  いつもの手前でぽんとする動きでなく）、卓のソリッドを上半身の長さの0.45だけ見えないまま持ち上げる。止めると手は
  ゆとりのところ（−0.24）で止まり、`--no-solid-stops` では0.25入る。

## キャラクターの打ち方

- パックの位置と速さだけを見る。0.12〜0.25秒の**反応の遅れ**（キャラクターごとに少し違う）のあとの、壁での跳ね返りを
  含めた行き先を読む。
- **守る**：パックが向かってくると、ゴールとパックの間（読んだ行き先の線の上）にマレットを置く。
- **打つ**：パックが手の届くところに来て、遅すぎなければ、狙う点（相手のゴールのどこか、または壁に当てて斜めに）へ
  向けてマレットを前に振る。狙いは少しずれる（ずれの大きさはキャラクターごとに少し違う）。
- **待つ**：パックが向こうの側にある間は、ゴールの前に戻って構える。
- 性格：攻め好き（前に出て強く打つ）・守り好き（ゴール前で待ち、返す）の間で、キャラクターごとに少し違える
  （モデル名から決める。いつも同じ）。
- 手の届く範囲（腕・傾き・横の一歩）の外へは行けない。めり込み判定で止められたところも同じ。
- 2人のとき：それぞれが自分の側の左右半分を受け持つ（少し重ねる）。パックがどちらの半分にあるかで、打つ人と守る人が
  入れ替わる。2人のマレットが重なりそうなら、守る人が避ける。
- 2人を相手にするとプレイヤーが不利なので、2人のときはプレイヤーのマレットを少し大きくし、キャラクターの反応を少し遅くする。

## 反応と手ぶり

いま作ってあるもの：ゴールのたびに顔（キャラクターが決めた：笑顔、決められた：困った顔。2.5秒で戻る）。対局が終わると
マレットから手を放し、勝てば拍手、負ければ「あちゃ～」（`EmoteSeated`）。Enterで次の対局を始めると、また手を伸ばして持つ。
以下は、これからのものも含めた設計。

- 立ったままの手ぶりを使う（`GeneratedMotion::EmoteSeated` の、腕・首・顔だけを動かす作り方を立ち姿で）。
  マレットは片手に持ったまま、もう一方の手で（両手の手ぶりは、マレットを台に置いてから）。
- **キャラクターが決めた**：小さくガッツポーズ（空いた手）、笑顔。
- **決められた**：「あちゃ～」（Oops）、首をかしげる。
- **いい打ち合い**（10回以上続いたあとのゴール）：どちらが決めても、笑う。
- **勝った・負けた**：マレットを置いて、拍手か、両手を頬に当てる・額に手を当てる。
- 2人のとき：相方の方を向いて頷く（味方が決めたとき）。

## 観戦するキャラクター

- 相手でないキャラクターは、麻雀と同じくウィンドウの横で観戦する（`UpdateWatching`、`src/main.cpp`。麻雀かエアホッケーの
  ウィンドウ、`GameWindowRect`）。避け方・向き・ときどきの仕草も麻雀と同じ。
- ゴールのたびに、ときどき小さく拍手する。

## しゃべる・写真・記録

- キャラクターの言葉は、頭のすぐ右の吹き出しに出る（麻雀と同じ作り。2Dでは向こうの端の右）。声の設定があれば声も出る。
  話している間は、顔を上げてこちら（カメラ）を見る（`MascotModel::LookToward`。前かがみの分も起こす。設定の「マウスの
  方を見る」が切ってあれば向かない）。
- 話すのは：対戦の始まり、ゴール（決めた・決められた。10回以上の打ち合いのあとは重く、それを言う）、マッチポイント（どちらかが
  あと1点）、対戦の終わり（勝った・負けた）。LLMがあれば、点数や打ち合いの長さを伝えて自分の言葉で1文話す（`AirHockeyOpponent::talk`
  → main の `GameTalk`。返事は `AirHockeyHeard`）。待つのは8秒まで。小さな出来事は10秒に1回まで（それ以外は用意したセリフ）。
- 観戦しているキャラクターも、麻雀と同じく、ときどき自分の吹き出しでひと言いう（`onEvent` → main の `WatchersHear`）。
- ウィンドウを閉じて戻ると、対戦の感想をひと言いう（最後までしたときは結果を、途中でやめたときはそのことを。`AirHockeyAfterword`）。
- スナップショットの `.txt` の `airhockey words:` に、出来事と言ったこと。
- 決めた瞬間と勝ったときに、自動でアルバムに写真を残す（Pキーでいつでも撮れる）。
- 記録はキャラクターごとに `characters\<モデル名>-<番号>.airhockey.txt`（UTF-8の `キー=値`）。
  遊んだ数、勝った数、2人相手での勝った数、いちばん長い打ち合い、いちばん速いパック。
- 最後まで遊ぶと、なかよし度が+3（1日に9まで。途中でやめたものは数えない。docs/Bond.md）。2人のときは2人とも。

## 確かめ方

- `MikuMikuDesktopPerch.exe --airhockey-sim out.txt [回数] [seed] [速さ1〜4] [大きさ1〜4]`：キャラクターの考え同士を対戦させ（あなたの側は上の
  「強さの目安」の考え）、パックが台の外に出ないか・マレットの中に入らないか・終わらない対局がないかを数える
  （1行目が「0 wrong」なら合っている）。勝ち数、1対局の点と長さ、置き直した回数、いちばん長い打ち合い、いちばん速いパックも書く。
- `--airhockey-shot out.png [秒] [seed]`：同じ2人をその秒数だけ遊ばせた画面を画像にする。
- `--snapshot out.png <フレーム> --airhockey`：本物のウィンドウを開き、あなたの側を同じ考えに打たせて（ウィンドウが
  前になくても止めない）、その画面を撮る。`.txt` の `airhockey:` の行に点数・時間・打ち合い・描いたフレームの数。
- これから：`--airhockey-hold x,z` で台の上のその点で持った姿、`--watcher <pmx>` で観戦、`.txt` に台の大きさと手の届く範囲。

## 作る順番

1. **めり込み判定とソリッドの共通処理**（`MascotModel`）。麻雀の卓で試す（手を伸ばす動きが卓に当たらないか）。済み。
2. 台の物理とマウス操作。キャラクターなしの2Dの台で、遊んで感触を確かめる。済み（強さは遊んで決める）。
3. マレットを持つ動き（`GeneratedMotion` の Hold）と、台の剛体。スナップショットで、いろいろな点で持った姿を確かめる。
   3Dの台とカメラも先に作った。済み（足の運び、空いた手はこれから）。
4. 相手1人の3Dと、キャラクターの打ち方・反応・音。
5. 相手2人（2体の描画・受け持ち・2人用の釣り合い）。
6. しゃべる・写真・記録・なかよし度、READMEへの追記。
