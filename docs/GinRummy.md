# ジンラミー（ミニゲーム）の設計

キャラクターと1対1で遊ぶ、アメリカで定番のカードゲームです。手札で組を作って、組にならない札の点数を減らし、先に100点を取ったほうが勝ちます。洋室の卓に、キャラクターが座って相手をします。

## 方針

- **ポーカーと同じ作り**：別のウィンドウで遊び、キャラクターはその間デスクトップから消えて、同じモデルが卓の向こうに座る。
  部屋は洋室（`src/WesternRoom.cpp`。チェスや他のトランプのゲームと共通）。卓・椅子・入ってきて座るまで・カメラの操作・吹き出し・観戦・デスクトップに戻ってからのひと言は同じ。
- 右クリックメニューの「ミニゲーム」→「ジンラミーをする」で、そのキャラクターが相手になる。いつでも閉じてやめられる（途中のEscは、Yでやめる、Nで続ける）。
- カードの絵はブラックジャックと同じ `res/blackjack/cards.jpg`。
- あなたの手札は読みやすいように、3Dの卓ではなく画面の下に大きく並べる。組はまとめて緑の線を付け、自動で並べ替える。

## ルール

- 1組52枚を使い、10枚ずつ配る。残りが山札で、1枚めくって捨て札にする。親（配る人）は毎回交代する。
- 最初の捨て札は、親でない人から順に、取るかパスするかを選べる。2人ともパスしたら、親でない人が山札から引いて始める。
- 自分の番は、山札か捨て札の一番上から1枚取り、1枚捨てる。捨て札から取ったカードを、そのまま捨てることはできない。
- **組**：同じ数3〜4枚、または同じマークで3枚以上の連番。連番ではAは2の下だけで、Q-K-Aは組にならない。
- **余り（デッドウッド）**：組にならない札の合計。Aは1、数はそのまま、J・Q・Kは10。組の分け方は、余りが一番少なくなるように自動で決める。
- **ノック**：1枚捨てたあとの余りが10点以下なら、そこで回を終わらせられる。相手は余りの札を、ノックした人の組に付け足せる（付け足し）。
- **点数**：相手の余りから自分の余りを引いた差が、ノックした人の点になる。
- **ジン**：余りなしで上がると、相手の余り＋25点。ジンのときは付け足しができない。
- **アンダーカット**：ノックされた側の余りが同じか少なければ、その差＋25点がノックされた側の点になる。
- 山札が残り2枚になって誰もノックしていなければ、その回はなしになる。
- 先に100点に届いたら、ゲームの終わり。多いほうの勝ち。

## キャラクターの打ち方

- 見えるもの（自分の手札、捨て札、あなたが捨て札から取ったカード）だけで考え、山札やあなたの手札は見ない。
- 捨て札は、組ができて余りがはっきり減るときに取る。
- 捨てるカードは、捨てたあとの余りと、まだ見えていないカードでどれだけ余りを減らせそうかで選ぶ。あなたが集めていそうなカードは捨てずにおき、あなたが捨てた数は安全とみる。
- ジンはすぐ上がる。回の前半は10点以下ならノックし、山札が減るとアンダーカットを避けて、余りがかなり少ないときだけノックする。

## 表情

キャラクターの顔は手の進み具合で変わる：ノックできそうなら笑顔、手が悪ければ困り顔。ただし、ときどき逆の顔を作る。

## 操作

- 山札から引く（D）、捨て札を取る（T、または捨て札のカードをクリック）、パス（P。最初の捨て札のときだけ）。
- 1枚引いたら、手札のカードをクリックして捨てる（矢印キーで選んでEnterでも可）。
- ノック（K）を押してからカードを選ぶと、ノックして捨てる。選べないカードは暗くなる。余りなしで上がれるときは、ボタンが「ジン」になる。
- 「遊び方」（Tab）でルールが見られる。「次へ」（Enter）で次の回へ。

## 卓と3D

- 向こうにキャラクターの手札（伏せたまま）、真ん中の左に山札、右に捨て札。カードは山札から飛んで配られ、回が終わると山札に戻る。
- 回が終わると、キャラクターの手札が表になり、組に金色のふちが付いて、余りは少し手前に置かれる。あなたの手札も、組、付け足した札、余りの順に並ぶ。
- キャラクターはカードを取るときや捨てるときに手を伸ばす。ジンやアンダーカットで、拍手か頬に手、または「あちゃ～」。あなたのジンには金色の光。
- 左上にキャラクターの点数、左にあなたの点数と余り、右上に何回目と山札の残り、右下に捨て札の一番上。
- 3Dで描けないときは2Dの画面で、カードを並べた図にする。

## 音・セリフ・なかよし度

- 音は麻雀・花札の札の音（`src/MahjongSound.cpp`）を使う。
- セリフは `res/ginrummy/lines.txt`（英語のときは `lines.en.txt`）の下書きから選ぶ。LLMによる言い直し、ユーザーのセリフファイルは麻雀と同じ。場面の一覧は `docs/GameLines.md`。
- 観戦しているキャラクターは、ゲームの始まり、ジン、アンダーカット、終わりで、ときどきひと言いう。デスクトップに戻ると、ゲームの感想をひと言いう。
- ゲームを最後まで遊ぶと、一緒に遊んだキャラクターのなかよし度が上がる（+3、1日に9まで。途中でやめたゲームは数えない）。

## 確かめ方

- `--ginrummy-test <out.txt>`：組と余りの数え方、決めた並びの山札で、最初の捨て札、ジン、付け足し、アンダーカット、取った札を捨てられないこと、山札切れを確かめる。1行目は失敗の数。
- `--ginrummy-play-test <out.txt> [count] [seed]`：キャラクターの打ち方どうし、すぐノックする相手、でたらめな相手とcount回ずつ遊び、カードの数が合うか・止まらないかを確かめて、勝ち負けを出す。1行目は「0 wrong」。
- `--ginrummy-shot out.png [steps] [seed] [help]` で2Dの画面を撮る（helpを付けると遊び方）。
- `--snapshot out.png 620 --ginrummy [steps]` で3Dの卓を撮る（stepsを指定すると、12秒後にその手数だけ進める）。
