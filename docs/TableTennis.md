# 卓球（ミニゲーム）の設計

キャラクターと1対1で打ち合う卓球です。台の向こうにキャラクターがラケットを持って立ち、あなたの側はラケットだけが見えます。

## 方針

- **ほかのミニゲームと同じ作り**：別のウィンドウで遊び、キャラクターはその間デスクトップから消えて、同じモデルが台の向こうに立つ。
  吹き出し・観戦・デスクトップに戻ってからのひと言は、ホバーホッケー（`docs/HoverHockey.md`）と同じ。
- 右クリックメニューの「ミニゲーム」→「卓球をする」で、そのキャラクターが相手になる。いつでも閉じてやめられる（途中のEscは、Yでやめる、Nで続ける）。
- **3D表示のみ**：球の高さが大事なので、2Dの画面はない（3D表示が作れないときは、そう伝えて閉じる）。
- **あなたの側はラケットだけ**：体は描かない。ラケットの高さは球に合わせて自動で動く。

## 操作

| 操作 | すること |
|---|---|
| マウスを動かす | ラケットを前後左右に動かす（遊んでいる間、カーソルはウィンドウから出ない） |
| 左クリック | 打つ（ドライブ） |
| 右クリック | カット |
| Space、マウスの戻るボタン | スマッシュ |
| 1〜3 | 相手の強さ（やさしい・ふつう・つよい。設定の `TableTennisLevel` に残る） |
| H | ラケットを持つ手（右利き・左利き。設定の `TableTennisLeftHanded` に残る） |
| P | 一時停止（クリックでも再開） |
| Esc | やめるか聞く（終わったあとは閉じる） |
| Enter | 終わったあと、もう一度 |
| 中ボタンのドラッグ | カメラを回す（Shift＋中ボタンで移動、ホイールで寄る・離れる、中ボタンのダブルクリックかF1で戻す） |

- ほかのウィンドウに移ると一時停止する。
- **フォアとバック**：球の行き先が分かったときに、打つ場所が、ラケットを持つ腕のひじのいまの位置より左（体の側）ならバックハンド（ラケットを体の中央の前に）、右ならフォアハンド（ラケットを体の右の外に）で取る。体に近い球をフォアハンドで取ると、腕を体に畳むことになるため。
  1球ごとに一度だけ決め、その球を打ち終えるまで変えない。球を待つあいだはフォアハンドの構えに戻る（台の中央より少し自分の左に立つので、中央の球はフォアハンドになる）。バックハンドのときは、ラケットの黒い面がこちらを向く。ラケットは握手の形で握る：手首は曲げず（手は前腕の延長）、前腕のひねり（手捩）だけで親指を上にしてラケットを立てる。ラケットは親指の上へ、手の向きに少し倒れて伸びる。面は手のひらの向きで、前腕が外を向くフォアハンドでは手のひら（赤い面）が前、前腕が体の前へ入るバックハンドでは手の甲（黒い面）が前、前腕が前を向いているときは面が横を向く。ひねりは可動域（80°）までで止める。腕の形も変える：フォアハンドはひじを体の脇に下げ、前腕が外（ラケットを持つ手の側）へ向く。バックハンドはひじを外に張り、前腕が体の前へ入る。
- **立ち位置**：球の行き先が分かった時点で、その取り方の場所へ体ごと横へ動く（ラケットより先に動き出す）。
- **体全体で打つ**（`MascotModel::HoldBody`。`MascotModel::Hold` のスタイル3と一緒に使う）：
  - 構え：ひざを曲げて少し沈む（グルーブ。なければセンター。足は床に残る）。低い球ほど深く沈む。
  - 球が来るまでの0.4秒：上半身を引く（フォアは右へ、バックは左へ）。下半身も半分ほど一緒に回る。
  - 打つ：引いた向きから反対へ振り抜き、戻る。ドライブはひざを伸ばして伸び上がり、カットは沈む。
  - **スマッシュ**：伸び上がってラケットを高く上げ、大きく引いてから、深く沈みながら前へ踏み込み、上半身を倒して振り下ろす。
  - 短い球には前へ、深い球には後ろへ、体を動かす（グルーブの前後）。
- **腕の振り**：球が来るまでにラケットを引き（フォアは体の右外・後ろへ、スマッシュは上へ）、打つときに前へ、体の反対側へ振り抜いて戻る（ドライブは上へ、カットは下へ、スマッシュは振り下ろす）。引いた位置から振り抜く途中で、当たり判定の位置を通る。
- **面を正面に**：打つときは、手首を少しだけ返して（40°まで。球を待つあいだは返さない）、面を相手へまっすぐ向ける。フォアハンドでは体の中央からラケットまでを離して構える（体の右外）。
- **足と、ラケットを持たない手**（`MascotModel::HoldFree`）：足を左右に開いて立つ（足ＩＫを外へ、脚の長さの0.15倍ずつ）。ラケットを持たない手は、ひじを曲げて体の前に構え、体の回転についていく。
- **サーブ**：キャラクターのサーブでは、ラケットを持たない手のひらに球を載せ（手首は曲げず、前腕のひねりで手のひらを上に向ける）、打つ0.55秒前に投げ上げる。球は手のひらから上がり、打たれる位置へ落ちてきたところで、腕を振って打つ（球が宙で止まって待つことはない）（当たり判定の球の位置は変えていない。見た目だけ）。
- **前後の立ち位置**：フォアハンドは球を体の横・少し前で打つ（打つ場所より0.30m後ろに体。前かがみで肩が前へ出る分を見込む）。バックハンドは体の前で打つ（0.45m後ろ）。短い球には台へ寄り、深い球には下がる（脚が台に入らないところまで）。
  球を打つ場所は、台の端から0.38m後ろあたりを選ぶ（横に立てるだけの余地を取る）。
- **足運び**：足は床に置いたまま体が動き、体が足から離れすぎたときだけ（左右は上半身の0.30倍、前後は0.22倍）、その足を持ち上げて置き直す（足ＩＫ）。小さな動きでは足は床に付いたままで、体だけが足の上で動く。進む側の足が先に出て、もう一方が後から寄るサイドステップで、両足が同時に浮くことはない。1歩は0.13〜0.23秒。止まっていれば足は動かない。
- **打つ瞬間のラケット**：振りは、引いた位置から、球が着く少し前に当たり判定の位置へ来て、打ち終わるまでそこに留まり、そのあと振り抜く（腕はならして動かす分だけ遅れるので、その分を見込む）。
- **届かない分は体を寄せる**：球が来るあいだ、手のラケットが左右にまだ届いていなければ、その分だけ体を左右へさらに動かす（体の正面の球で腕が回り込めないとき）。
- **滑らかに動く**：体の上下・前後・回転、ラケットの高さ、横への移動は、行き過ぎないばねで追う（動き出しと止まりがゆるやか）。腕と体のボーンは、さらに2段でならしてから渡すので、急に動き出すことがない。
- **届かなければ空振り**：振り始めるときに、キャラクターの手が持っているラケットが、当たり判定の位置（か、引いた位置の目標）から左右に25cm以上離れていれば、振っても当たらない（球はそのまま抜ける）。
  球を待つあいだ、手のラケットが目標からずれている分は、手首の行き先に足して詰める。遠い球には大きく動いて追いつき、間に合わなければ空振りする。
- **腕が体に入らないように**：腕が体の前を横切るときは、前腕だけでなく上腕も、そのモデル自身の体の表面（`GeneratedMotion` が持つ、立ち姿の体の頂点）より前に出るまで、
  手首を前と外へ逃がす（`MascotModel::Hold` のスタイル3）。体の厚みや腕の長さ、初めの腕の角度がモデルごとに違っても、そのモデルの形で判定する。

## しゃべる・反応

- セリフは場面ごとに用意してあります（`res/tabletennis/lines.txt`。場面の一覧と書き方は `docs/GameLines.md`）。
- 点が入るたびに、キャラクターの表情が少し変わる（取れば笑顔、取られれば困り顔）。
- 試合が終わると、勝てば拍手、負ければ「あちゃー」のしぐさ。
- ウィンドウを閉じて戻ると、試合の感想をひと言いう（最後までしたときは結果を、途中でやめたときはそのことを）。
- 相手でないキャラクターは、ウィンドウの横で観戦する。

## 軌跡とキラキラ

- 球のうしろに、0.4秒ぶんの光の軌跡が残る。速いほど明るく、ゆっくりのカットではほとんど見えない。あなたの球は水色、キャラクターの球はピンク、スマッシュは金色で太い。
- スマッシュは、打った瞬間に星が飛び散り、軌跡からきらきらした粒がこぼれる。

## 音

球が台で弾む音は、木を叩くような硬い「カッ」という音。ラケットに当たる音は、それより少し高く、小さい（スマッシュは少し大きい）。
ネットにかかる音は低く鈍い。ファイルは使わず、その場で作る短い音。

## 確かめ方

- `MikuMikuDesktopPerch.exe --tabletennis-sim out.txt [回数] [seed]`：3つの強さそれぞれと、マウスと同じ打ち方をする考えとを対戦させ、
  あってはならないこと（球がなくなる、打ち合いが終わらない、試合が終わらない）を数える。1行目が `0 wrong` なら問題なし。
- `--snapshot out.png <フレーム> --tabletennis`：本物のウィンドウを開き、あなたの側を同じ考えに打たせて（音は出さず、ウィンドウが前になくても止めない）、その画面を撮る。
  `--tabletennis-level 1〜3` で強さ、`--tabletennis-camera pitch,distance,yaw` でカメラ、
  `--tabletennis-aim x` であなたの球を全部その横位置（m。0.6でキャラクターのバック側）へ打たせる。
  `.txt` の `tabletennis:` の行に、点数・時間・打ち合い・描いたフレームの数と、キャラクターが打ったときの、手のラケットとゲームの中のラケットとのずれ、
  手が届かずに空振りした回数、ラケットを持つ腕が体の表面のゆとり（脚の長さの0.045倍）の内側に残った深さのいちばん大きい値（脚の長さを1として。0.045より小さければ体には入っていない）。
  `tabletennis words:` に、出来事と言ったこと。
