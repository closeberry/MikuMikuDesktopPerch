# 生成モーションのルール

[English](MotionRules.en.md)

MikuMikuDesktopPerch がプログラムで生成・上乗せするモーションは、MMDモーションの基本的な作法に従います。
VMDとして書き出したときに、そのまま他のモデルやツールで使える状態を保つためです。

## ボーンごとの制約

- **全ての親**：動かさない。
- **センター**：Y軸回転は使わない。体の向きは上半身と下半身の回転で変える。上下移動もしない。X・Z方向の移動は使ってよく、モデルが移動するとき（歩くなど）はセンターで移動する。
- **グルーブ**：上下移動だけを使う。
- **ひじ**：ローカルY軸の回転だけを使う。ローカルZ軸では曲げない。ローカルX軸の捩りは腕捩りで表す。
- **手首**：ローカルX軸の回転は使わない。捩りは手捩りで表す。

## ローカル軸と捩り

- ローカル軸がモデルに設定されていない場合は、骨格（ボーンの位置と接続先）から自前で計算する。
- 捩りボーン（腕捩・手捩）がないモデルでは、上の捩りの制限は適用しない。
- 生成するモーションは捩りを直接使わない。必要な捩りは**捩り自動分散**（ひじ・手首に生じた捩り成分を腕捩・手捩に再配分する処理）に任せる。

## 実装（`src/GeneratedMotion.*`）での守り方

- 書き込むボーン：センター（X移動のみ）、グルーブ（Y移動のみ）、下半身・上半身・首（回転）、左右の足ＩＫ（移動と回転）、腕・ひじ・腕捩・親指以外の指（回転）
- 生成中は、待機VMDの傾きが残らないよう、センターの回転・上半身2・頭・肩・手首・手捩・つま先ＩＫを初期姿勢に固定する（肩は下の「肩」のとおりしぐさで腕を動かすときだけ、手首と手捩は下の「手の向き」のしぐさでだけ回す）
- 腕の振りとひじの曲げは、骨の向きと正面方向から求めた「前へ曲げる軸」まわりの回転だけで作る。モデルのローカル軸は、X軸が骨の向きとおおむね揃っている場合だけ使う
- ひじの回転は最後に捩り自動分散（`DistributeTwist`）を通す。ローカルXまわりの成分は腕捩へ移し、残りはローカルYまわりの成分だけを残す（ローカルZは捨てる）
- 歩くときはセンターを進め、接地している足ＩＫは空間上に固定する。全ての親は一切動かさない
- 足の傾き（かかとを上げる・つま先を上げる）は足ＩＫの回転で付ける。かかとを上げるときはつま先を支点に、つま先を上げるときはかかとを支点に回るよう、足ＩＫの位置も合わせて動かす（つま先やかかとが地面に沈まないように）
- 立ちポーズで腕を下ろす角度は、モデルごとに決める。手が横にあるもの（腰、太もも、スカート）に当たらない範囲でいちばん下ろした角度を、モデルのメッシュ（髪と腕自身の頂点は除く）から測る。水平から72°〜86°の範囲で、72°より外へは広げない（開いたコートのように横に垂れる服で腕が広がりすぎないように）
- 待機中の重心移動はセンターのX移動（腰を片足の上へ）と下半身・上半身のZ回転で表す。足ＩＫは固定したまま
- 待機中のしぐさ（腰に手、手を振る、ピースなど）は、手首の目標位置から求めた2関節IKで腕・ひじを決める。腕は長さ方向にも回してひじの曲がる面を合わせ、ひじは曲げ軸まわりだけ、手首はふだん回さない
- 手の向きが大事なしぐさ（拍手の手のひらを向かい合わせる、下げた手を前で重ねる）では、腕とひじを決めたあと、指の向きと手のひらの向きの目標から手の回転を求め、そのうち前腕の長さ方向（捩り）の分を手捩に、残りを手首に入れる（手首はローカルX軸で回さない。手捩のないモデルでは全部を手首に入れる）
- 手のひらどうしを合わせるしぐさ（拍手）では、手首ではなく手のひらの面を目標の位置に置く。手のひらの面は、モデルごとに、手首の頂点（手首のウェイトが大きい頂点）が手のひら側にいちばん出ている所から求める。肩幅、腕の長さ、立ちポーズ（Tスタンス・Aスタンス）、手の厚みが違っても、手のひらが離れたり突き抜けたりしない
- あくびでは、口に持っていく手の手のひらを口に向け、手のひらの面を口のすぐ前に置く。指は顔を横切って反対側へ向ける。口の位置は「あ」モーフが動かす頂点（グループモーフはその中身の頂点モーフまでたどる）の、動く量で重みをつけた中心で、モデルごとに求める。頭を後ろへ傾ける分だけ目標も頭といっしょに動かす
- 体の前を横切る腕（考えるポーズで下ろした方の腕など）は、前腕と手を体の前の面と照らし合わせ、体に入る分だけ手首の目標を前へ出してから腕とひじを求め直す。体の前の面は、モデルのメッシュ（髪と腕は除く）から求める
- **肩**：しぐさで腕を動かすとき（腕とひじを2関節IKで決めるとき）は、MotionTraceEditor の肩の自動生成と同じ式で肩を回す。腕を自然に下ろしたときのひじの位置からのずれを上腕の長さで割り、上がった分×42°（下がった分×14°）、前に出た分（体の中心へ寄った分の0.65、外へ離れた分の0.35を足す）×26°（後ろは×18°）。上は50°、下は15°、前後は20°まで（手を振る、ピース、髪を耳にかける、あくび、あごに手を当てる、遠くを見る、ほっぺを押さえるのように手を顔の高さまで上げるしぐさでは、ひじが肩の高さほどなので半分にする）。肩を回すと腕の付け根が動くので、動いた付け根から腕とひじを求め直し、手は目標の位置に届かせる。ユーザーが登録したモーション（待機モーションなど）の上に重ねるときは、肩はモーションのままにし、その肩から腕とひじを求める
- クリックの反応も同じしぐさの仕組みで作り、立ちポーズ・しぐさ・待機VMDの上に重ねる。書き込むボーンと制約はしぐさと同じ
- ユーザーが指定した歩き・走りのVMD（その場で足踏みするもの）を使うときも、横を向かせるのは生成の歩きと同じく、足ＩＫの位置と回転を鉛直軸まわりに回し、下半身・上半身・首の回転を足すことで行う。VMDのセンターの上下はグルーブへ移し、センターはX・Z移動だけにする。進む速さは、接地している足ＩＫが後ろへ滑る速さから求める
- 表情（会話の気持ち）とうとうとは、まばたき・呼吸・視線と同じ上乗せの層で作る。表情はモーフだけ、うとうとはまばたきモーフと首・頭・上半身の回転だけを使う
- 座るときは、太ももを斜め下に下げる（ひざを上げるとスカートを貫通しやすいため）。体の向きは下半身のY回転で横に向け、上半身と首で正面へ振り向く（センターは回さない）
- ぶら下がる・ジャンプのかがみ込みでも、体を傾けるのは上半身・下半身の回転、高さを変えるのはグルーブだけで行う（センターは回転・上下移動しない）
- ジャンプや落下の上下移動はモーションに含めず、ウィンドウの移動で表す
- ぶら下がる（懸垂）では、ひじを上へ曲げるために腕ボーンを長さ方向に回す。ひじは曲げ軸まわりの回転だけで、捩りは使わない
- 生成中の指は、まっすぐ伸ばさず軽く曲げておく（人差し指から小指へ少しずつ深く）。しぐさや休憩ポーズはその上から自分の曲げ方にする
- 指は親指以外を、手のひら側へ曲がる軸（人差し指と小指の付け根を結ぶ向き）まわりにだけ回す
- ワープの回転・縮小は描画だけの変換で、センターや全ての親には書き込まない
- キャラクター同士のおしゃべりで相手の方へ向き直るときは、下半身と上半身（下半身の子でないとき）をY回転させ、左右の足ＩＫ（と、足ＩＫの子でないつま先ＩＫ）の位置を両足の間の点を中心に鉛直軸まわりに回し、回転も同じだけ足す。センターと全ての親は回さない
- おしゃべりの相手の目を見るときは、視線と同じ上乗せの層で、自分の目から相手の目（左目・右目ボーンの位置）への向きに合わせて首と頭を上げ下げする

## 既存の補正との関係

- Tスタンス補正（`MascotModel` の腕の補正回転）は、モデルのレスト姿勢の差を吸収する表示用の補正であり、モーションデータ自体には含めない。
