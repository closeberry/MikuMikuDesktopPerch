# 遺跡の探検（メトロイドヴァニアのミニゲーム）の設計

キャラクターが、横から見た固定のマップの遺跡を探検するアクションゲームです。アイテムを取って
できることを増やし（二段ジャンプ・ダッシュ・壁蹴り…）、前は通れなかった場所へ戻って先へ進み、
いちばん奥のラスボスを倒すと終わり。マップは毎回変わらず、いつも同じ。

右クリックメニューの「遺跡を探検する」で始める（ゲームの名前は「遺跡の探検」）。ファイル名・コードでは `Metroid` を使う。

## いまの段階

2段階目からは保留（2026-10-29）。敵・武器・アイテムなどの見た目を描く人（美術）が要るため。
保留の間は右クリックメニューに「遺跡を探検する」を出さない（コードは残し、`--snapshot ... --metroid` では開ける）。

1段階目まで（`src/Metroid.cpp` の Map と Game、`src/MetroidWindow.cpp`、地図は `res/metroid/map.txt`）。
右クリックメニューの「遺跡を探検する」で、彼女はデスクトップから消え、入口の回廊（6部屋・9画面）を走って跳ぶ。

- タイルは彼女の高さ（モデルの大きさ）の1/2.5。体の箱は幅0.72・高さ2.2タイル。走る速さは6タイル/秒（0.1秒で全速、
  0.08秒で止まる）、ジャンプは長押しで3.3タイルまで（早く離すと上がる勢いを0.45倍に）、落ちるのは22タイル/秒まで。
  足場から落ちて0.1秒・着地の0.1秒前の押しも跳べる。`=` の足場は下から跳んで抜けられる（上から下へ降りることはできない）。
- ゲームパッド（XInput、つないである最初の1つ。つないでいなければ2秒ごとに探す）：左スティックか十字キーで走る、Aでジャンプ、
  STARTで「遺跡を出ますか？」（Yで出る、BかSTARTで続ける）。キーボードと一緒に使える。ゲームパッドがあると、下の操作の説明もそちらになる。
- 部屋は画面の格子の上に置き、辺で開いているところどうしがつながる（扉はこれから）。部屋を出ると隣の部屋に入り、
  カメラは部屋の中だけを動く。
- 3D：岩のタイルごとに手前の面（レンガ）、上が空いていれば床の石畳、横・下の面、空いたタイルの奥に暗めの壁。
  見た目はダンジョンのシェーダーの「苔むした石の遺跡」。カメラは横から8°見下ろし、縦に12タイル見せ、向いている方を
  少し広く、なめらかに追う。彼女は進む向きから17°カメラの方へ向き、振り向くときは正面を通って回る。
- 動き：地上で走る（`SetFacingWalk` の走りを、足が滑らないよう走る速さに合わせた歩調で）、空中は新しい `Activity::Air`
  （かがまずに跳び、上がるときはひざを引き上げ、下りるときは脚を下へ伸ばして腕を開く。上下の速さから0.12秒かけて移る）、
  着地で `Land` のかがみ。空中では髪やスカートが少し浮く（`SetCarryMotion`）。
- ウィンドウから離れると止まり、キーかクリックで続く。Escで「遺跡を出ますか？」（Y／N）。
- 3Dで描けないときは、いる部屋をタイルの2Dで描く（彼女は丸い形と名前）。
- 確かめ方：`--metroid-check out.txt`（地図の検査。1行目が「0 wrong」）、
  `--snapshot out.png N --metroid [部屋の番号] --metroid-play "R1.8 RZ0.35 R2"`（キーを順に押したことにして撮る。
  `.txt` の `metroid:` に部屋・位置・速さ・跳んだ回数など）。

## 方針

- **キャラクター自身を操作する**（ダンジョンと同じ）。彼女はデスクトップから消え、同じモデルが遺跡の中を走り、跳び、
  剣を振る。PMXやモーションを二重に読み込まない（`inMetroid`。ダンジョン・麻雀・エアホッケーと同じ扱い）。
- **見た目は3D、遊びは2D**（2.5D）：計算は横と縦だけ（奥行きなし）。カメラは真横から少し上を見下ろし、彼女を追う。
  3Dで描けないときは、タイルを2Dで描き、彼女は顔の切り抜きと簡単な形で出す。
- **マップは固定**：テキストファイル（`res/metroid/map.txt`）にタイルで書いておき、exe に入れる。毎回同じ。
- **リアルタイムのアクション**だが、やさしめ：落ちても穴の手前に戻るだけ（少しのダメージ）、やられてもセーブした所から
  取ったアイテムはそのまま。HPの回復は多め。アクションが苦手でも最後まで行けるくらい。
- **長さ**：初めてで1時間半〜2時間ほど、全部集めて3時間ほど。いつでも閉じてやめられ、次は最後のセーブから。
- **キャラクターと一緒にいること**を生かす：アイテムを取った・ボスを見つけた・倒したときに話す、セーブ地点で休んで話す、
  写真に残す、観戦する他のキャラクター、戻ってからの感想。
- 動きは**入りと抜きをなめらかに**：走り出し・止まり・着地・向きを変えるときに、ポーズがぱっと切り替わらないように。
  ただし操作への応答は遅らせない（体の計算はすぐ、見た目のポーズだけをなめらかに追わせる）。

## 操作

| キー | すること |
|---|---|
| ←→（A/D） | 走る（押した瞬間から動き、0.1秒で全速。離すと0.08秒で止まる） |
| ↑↓（W/S） | 扉に入る・セーブ地点で休む（↑）、しゃがむ（↓） |
| Z（スペース） | ジャンプ（長く押すほど高い。空中でもう一度：二段ジャンプ、取ってから） |
| X（J） | 剣（地上・空中。↓を押しながら空中で：下突き、取ってから） |
| C（K） | 魔法の弾（取ってから。MPを使う） |
| Shift（L） | ダッシュ（取ってから。地上でも空中でも、横に短く速く） |
| M | 全体マップ（行った部屋・見つけたアイテムの印・セーブ地点） |
| P | 写真 |
| Esc | 一時停止（Yでやめる、Nで続ける） |

- ジャンプの入力は、着地の0.1秒前の押しも受け付け、足場から落ちて0.1秒の間も跳べる（気持ちよく跳べるように）。
- ゲームパッド（XInput）でも同じことができる：左スティック・十字キーで走る（↑↓も）、Aでジャンプ、Xで剣、Bで魔法の弾、
  RBでダッシュ、BACKで全体マップ、STARTで一時停止（Yでやめる、Bで続ける）。

## マップ

- **タイル**：1タイルは彼女の身長の1/2.5（彼女は2.5タイルの高さ、2タイルの段差は普通のジャンプで上がれる）。
  1画面は横28×縦16タイル。部屋は1画面か、横か縦に何画面かつながったもの。カメラは部屋の中だけを動く
  （部屋の外は見せない）。部屋と部屋は扉か、画面の端でつながる。
- **規模**：5つの地域、全部で45部屋ほど。セーブ地点は各地域に2つ、地域の行き来の近道（ワープの石碑）は後半に開く。

| 地域 | 見た目 | ここで取るもの | ボス |
|---|---|---|---|
| 1. 入口の回廊 | 苔むした石の遺跡（ダンジョンの6〜10階の見た目） | ダッシュ | 石の番人（ゴーレム） |
| 2. 地下水路 | 水の流れる古いレンガ（水浸しの見た目） | 二段ジャンプ | 大スライム |
| 3. 氷の洞窟 | 霜の岩、氷の床（すべる） | 壁蹴り | 氷の大コウモリ |
| 4. 溶岩の坑道 | 黒い岩と赤く光るひび | 魔法の弾・下突き | 炎の騎士（ガイコツの大きいもの） |
| 5. 星の塔 | 紫水晶と金の枠（いちばん奥、上へ登る） | — | ラスボス：古竜 |

- 地域の順はおおよそ1→2→3→4→5だが、行き止まりや戻り道を作る（取ったもので前の地域の奥へ行ける）。
- 見た目は、ダンジョンの階の見た目（シェーダーで位置から作る石・レンガ・氷・溶岩・水晶）を、横から見た形で使う。

## パワーアップ（アイテム）

| アイテム | できること | それで通れるようになる場所 |
|---|---|---|
| 剣（はじめから） | 前に斬る（光の刃。ダンジョンの剣と同じ見た目） | — |
| 風のくつ（ダッシュ） | 横に5タイル、0.25秒で駆ける（空中でも1回） | 広い穴、閉まりかけの扉、風で押し戻される通路 |
| 羽根の髪飾り（二段ジャンプ） | 空中でもう1回跳ぶ | 高い段差、高い所の扉 |
| 星の手袋（壁蹴り） | 壁に触れて落ちる速さが遅くなり、跳ぶと反対へ蹴り出す | 縦に長い穴を登る |
| 魔法の杖（魔法の弾） | 遠くへ光の玉を撃つ（MPを使う） | 遠くのスイッチ、魔法でしか壊れない封印の扉 |
| 重い靴（下突き） | 空中で↓＋剣：真下へ突き下りる | ひびの入った床を割って下へ |
| 命のかけら（12個、4つで最大HP+1） | — | — |
| 魔力のかけら（8個、2つで最大MP+1） | — | — |
| 地図の石板（各地域に1つ） | その地域の全体マップがわかる | — |

- アイテムは台座の上で光っている。取ると、短い演出（彼女が手に取って掲げ、名前と使い方が出る）。
- 取ったアイテムはセーブとは別に、取ったその場で記録する（取り直しはない）。

## 敵

- ダンジョンのモンスターの形（`MonsterArt`）を横から見た形で使う：スライム（跳ねる）、コウモリ（波のように飛ぶ）、
  ガイコツ（歩いて剣を振る）、ゴースト（壁を抜けてゆっくり寄る）、ゴーレム（遅いが硬い）、ゴブリン（投げナイフ）。
- 敵は部屋に入るたびに元に戻る（固定の配置）。倒すと小さな回復の玉を落とすことがある。
- 当たるとダメージを受けて少し飛ばされ、1秒は無敵（体が点滅）。

## ボス

- 各地域の奥に1体。ボスの部屋は入ると扉が閉まり、倒すと開いて、その地域のアイテムへの道が開く。
- 動きはいくつかの型の組み合わせ（突進・跳びかかり・弾を撃つ・呼び寄せる）。HPが半分を切ると型が増える。
- ラスボスの古竜は2段階：首と炎で戦う1段階、飛んで上から来る2段階（取ったものを全部使う：ダッシュで炎をくぐり、
  二段ジャンプと壁蹴りで頭まで登り、下突きと魔法で弱点を打つ）。
- 倒すとエンディング：遺跡を出て、彼女が振り返ってひと言。かかった時間・集めた割合を出す。

## セーブ

- セーブ地点（光る石碑）で↑を押すと休む：HPとMPが全部戻り、セーブする。彼女が冒険のことをひと言話す。
- やられると、最後のセーブ地点から（取ったアイテムはそのまま。倒したボスもそのまま）。
- 記録はキャラクターごとに `characters\<モデル名>-<番号>.metroid.txt`（UTF-8の `キー=値`）：いまの場所（セーブ地点）、
  取ったアイテム、倒したボス、行った部屋、遊んだ時間、クリアの回数といちばん早いクリア・集めた割合。
  クリアしたあとは「はじめから」も選べる（クリアの記録は残る）。
- 何か取るたび・セーブ地点で保存するので、途中でアプリを閉じても失われない。

## 3Dと動き

- カメラは真横から（少し上から、10°ほど見下ろす）。彼女を画面の真ん中より少し後ろ（向いている方を広く）に置いて追い、
  部屋の端では止まる。動きはばねでなめらかに（ジャンプの上下にはゆっくり付いていく）。
- 彼女は進む向き（左右）に体を向ける（`SetTurn`。向きを変えるときは0.12秒で回す）。
- 動き（`GeneratedMotion` に足すもの）：
  - 走る：前向きの走り（`SetFacingWalk` の走り）を、地面の速さに合わせて。
  - ジャンプ：いまのジャンプはかがんでから跳ぶ（0.22秒）ので、すぐ跳ぶ形を新しく足す：踏み切り（0.06秒）・上がる・
    頂点で脚をたたむ・落ちる（脚を伸ばし腕を少し上げる）・着地（速さで深さの変わるかがみ。`Land`）。
    体の高さはゲームが決め、ポーズは上下の速さから選んでなめらかに移す。
  - 二段ジャンプ：空中でひざを抱えて前に1回転（0.3秒）。
  - ダッシュ：前かがみで脚を前後に開いた形、後ろに光の筋。
  - 壁に張りつく：壁の側の手と足を壁に付け、ゆっくり滑り下りる。壁蹴り：壁を蹴って反対を向く。
  - 剣：いまの `Strike` は止まってから振るので、走りながら・空中でも振れる上半身だけの斬りを足す（0.25秒）。
    下突き：剣を真下に向けて落ちる。
  - 魔法：手を前に突き出す（上半身だけ）。
  - 当たった：のけぞり。やられた：ひざをつく。
  - アイテムを取る：両手で掲げる。セーブ地点で休む：座る。
- 部屋の物：台座のアイテム（光る）、扉（地域ごとの形）、セーブ地点の石碑、スイッチ、ひびの入った壁と床、トゲ、
  動く足場、水（地下水路）、溶岩（触れるとダメージ）。`PropArt` と同じく立体の組み合わせで作る。
- 背景：部屋の奥に壁（シェーダーの石・レンガ）と、遠くの景色（暗い柱の並び、地域ごとの色の光）を少し遅れて動かす。

## 会話

- 彼女の言葉は画面の上の吹き出しに出る（エアホッケーと同じ作り、1文字ずつ）。
- 話す場面：遊び始め（続きから・はじめから）、新しい地域に着いた、アイテムを取った（アイテムごと）、
  ボスを見つけた・倒した、やられた、セーブ地点で休んだ、行き詰まったとき（ヒント：同じ部屋に3分いる、
  行ける所を全部回ったのに次へ行けない）、ラスボス、クリア。
- セリフは、ウィンドウを開いたときにLLMにまとめて頼む（エアホッケーの `Prefetch` と同じ：場面ごとに3つずつ。
  `MetroidOpponent::prefetch` → main の `PrefetchLines`、答えは `MetroidLines`）。その場面が来たら、頼んであったものから
  1つすぐ言う。届いていない・LLMがないときは用意したセリフ。アイテムの使い方の説明やヒントは、LLMでなく決まった文で出す
  （まちがえると困るので）。
- セーブ地点で休むと、それまでの冒険をLLMにひと言で話してもらう（ダンジョンの焚き火と同じ。待つ間は「…」）。

## 観戦

- 他のキャラクターは、麻雀・エアホッケーと同じくウィンドウの横で観戦する（`UpdateWatching`、`GameWindowRect`）。
- アイテムを取った・ボスを倒した・やられたときに、ときどきひと言（`onEvent` → `WatchersHear`）。

## 戻ったときの感想

- ウィンドウを閉じて戻ると、ひと言（`MetroidAfterword`、エアホッケーと同じ形）：今回取ったもの・倒したボス、
  クリアしたならそのこと、途中ならどこまで行ったか。

## 写真・なかよし度

- Pキーでいつでも。自動で：アイテムを取って掲げたとき、ボスを倒したとき、クリアしたとき。
- ボスを倒すと、なかよし度+3（1日に9まで。docs/Bond.md）。クリアで+3。
- なかよし度で少し助ける（冷たくても不利にはしない）：段階2以上でセーブ地点で最大HP分より少し多く回復…などは後で決める。

## 確かめ方（作りながら足す）

- `--snapshot out.png N --metroid [部屋名]`：本物のウィンドウを開き、その部屋に彼女を置いて撮る。
  `--metroid-play <台本>`：決めたキー入力を流して動かす（例：`R1.0 Z0.3 R0.5`）。`.txt` の `metroid:` の行に、
  部屋・位置・速さ・地面にいるか・いまの動き・取ったアイテム。
- `--metroid-items all`：アイテムを全部持った状態で始める（後半の部屋を試す）。
- `--metroid-check out.txt`：マップの検査。全部の部屋がつながっているか、扉の両側が合っているか、アイテムを取る順に
  たどって（取ったものでだけ通れる所を考えて）、ラスボスまで行けるか・全部のアイテムに届くか。行き詰まりがあれば書く。
- `--metroid-map out.png`：全体マップを画像に。

## 作る順番

1. **地形と体の動き**：ウィンドウ（右クリックメニュー「遺跡を探検する」）、マップファイルの読み込み（最初の地域の
   6部屋ほど）、タイルの当たり判定、走る・跳ぶ・落ちる・扉で部屋を移る。3Dの横からのカメラで彼女が走って跳ぶ
   （ジャンプのポーズは新しく足す）。2Dの表示。`--snapshot --metroid`、`--metroid-play`。
2. 剣・敵・HP・やられる・セーブ地点と記録。
3. パワーアップ（ダッシュ・二段ジャンプ・壁蹴り・魔法・下突き）とその動き、全体マップ、`--metroid-check`。
4. 全部の地域の部屋と見た目、ボス4体とラスボス、エンディング。
5. 会話・観戦・感想・写真・なかよし度、README とリリースノートへの追記。
