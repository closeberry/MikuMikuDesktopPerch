# ページワン（ミニゲーム）の設計

キャラクターと1対1で遊ぶ、トランプの昔からのゲームです。場札と同じマークか同じ数のカードを出していき、先に手札を出し切ったほうがその回の勝ち。残った相手の札の点数を取り、先に150点を取ったほうが勝ちます。洋室の卓に、キャラクターが座って相手をします。

## 方針

- **ジンラミーと同じ作り**：別のウィンドウで遊び、キャラクターはその間デスクトップから消えて、同じモデルが卓の向こうに座る。
  部屋は洋室（`src/WesternRoom.cpp`。チェスや他のトランプのゲームと共通）。卓・椅子・入ってきて座るまで・カメラの操作・吹き出し・観戦・デスクトップに戻ってからのひと言は同じ。
- 右クリックメニューの「ミニゲーム」→「ページワンをする」で、そのキャラクターが相手になる。いつでも閉じてやめられる（途中のEscは、Yでやめる、Nで続ける）。
- カードの絵はブラックジャックと同じ `res/blackjack/cards.jpg`（ジョーカーはババ抜きと同じ）。
- あなたの手札は読みやすいように、3Dの卓ではなく画面の下に大きく並べる。マークごとに分け（黒と赤が交互になる順）、8とジョーカーは右端。枚数が増えると詰めて並べる。

## ルール

- 1組52枚とジョーカー1枚を使い、7枚ずつ配る。残りが山札で、1枚めくって場札にする（2・8・J・A・ジョーカーが出たら山札の下に戻して、めくり直す）。親（配る人）は毎回交代し、親でない人から始める。
- 自分の番は、場札と**同じマークか同じ数**のカードを1枚出す。出せないとき（出したくないときも）は山札から1枚引く。引いたカードが出せれば、そのまま出してもよい。出さなければ番が終わる。
- **2**：次の人は2枚引く。2を持っていれば重ねて返せて、合わせた枚数が次の人へ回る（ジョーカーでも返せる）。返さなければ、その枚数を引いて番が終わる。
- **J**：相手を飛ばす。**A**：順番を逆にする。二人ではどちらも、出した人がもう一度出すことになる。
- **8**：いつでも出せて、次のマークを決める。
- **ジョーカー**：いつでも出せて、次のマークを決め、次の人は4枚引く（2では返せない）。
- **ページワン**：残り1枚になるカードを出すときに「ページワン」と宣言する。言い忘れたまま相手の番になり、相手に指摘されると2枚引く。指摘できるのは、指摘する人が出すか引くかする前まで。
- **上がり**：手札を出し切った人がその回の勝ち。最後の札が2かジョーカーなら、相手はその分を引いてから数える。
- **点数**：相手の残り札の合計が、上がった人の点になる。数札（3〜7、9、10）はその数、Q・Kは10、2・J・Aは20、8とジョーカーは50。
- 山札がなくなったら、場札の一番上を残して残りを切り混ぜ、山札にする。
- 300手を超えても決着がつかなければ、その回はなし。
- 先に150点に届いたら、ゲームの終わり。多いほうの勝ち。

## キャラクターの打ち方

- 見えるもの（自分の手札、場札、あなたの手札の枚数、あなたが引いたときのマーク）だけで考え、山札やあなたの手札は見ない。
- 出せるカードはいつも出す。どれを出すかは、出したあとに続けやすいマーク（自分が多く持っているマーク、あなたが持っていなさそうなマーク）か、点の高い札を早めに出すか（あなたの残りが少ないとき）で選ぶ。
- 8とジョーカーは取っておき、出せる札がないとき、あなたが残り少ないとき、自分が上がれるときに使う。8で決めるマークは、自分が一番多く持っているマーク。
- 2で攻められたら、2かジョーカーがあれば返す。あなたの残りが少ないときは、2・J・Aを積極的に使う。
- 「ページワン」はたいてい言い、あなたが言い忘れたらたいてい指摘する。

## 表情

キャラクターの顔は手札の枚数で変わる：残り2枚以下なら笑顔、あなたより4枚以上多ければ困り顔。ただし、ときどき逆の顔を作る。

## 操作

- 出せるカードをクリックして出す（矢印キーで選んでEnterでも可）。出せないカードは暗くなる。
- 8かジョーカーを出すと、次のマークのボタンが出る（1〜4キーでも選べる。Escでやめる）。
- 山札から引く（D、または2Dの山札のクリック）。2やジョーカーで引く枚数があるときは、ボタンが「N枚引く」になる。引いたカードが出せないときは、そのまま番が終わる。出せるときは、出すか「出さずに終える」（K）。
- 残り2枚のとき「ページワン！」（O）を押してからカードを出すと、宣言して出す。キャラクターが言い忘れたら、自分の番に「言ってない！」（C）。
- 「遊び方」（Tab）でルールが見られる。「次へ」（Enter）で次の回へ。

## 卓と3D

- 向こうにキャラクターの手札（伏せたまま、多いと詰めて並ぶ）、真ん中の左に山札、右に場札。場札は1枚ずつ少しずつずれて重なる。8かジョーカーでマークが決まると、場札の下にそのマークの色（黒か赤）のふちが付く。
- 回が終わると、キャラクターの手札が表になる。
- 右下に場札の一番上、その左に今のマーク（8やジョーカーで決まったときは光る）と、引く枚数（+2など）。キャラクターが8で決めたマークや「ページワン」は、画面の真ん中にも少しの間出る。
- キャラクターはカードを出すときや引くときに手を伸ばす。キャラクターが上がると拍手か頬に手、あなたが上がると「あちゃ～」。あなたが上がると金色の光。
- 3Dで描けないときは2Dの画面で、カードを並べた図にする。

## 音・セリフ・なかよし度

- 音は麻雀・花札の札の音（`src/MahjongSound.cpp`）を使う。
- セリフは `res/pageone/lines.txt`（英語のときは `lines.en.txt`）の下書きから選ぶ。LLMによる言い直し、ユーザーのセリフファイルは麻雀と同じ。場面の一覧は `docs/GameLines.md`。
- 観戦しているキャラクターは、ゲームの始まり、上がり、終わりで、ときどきひと言いう。デスクトップに戻ると、ゲームの感想をひと言いう。
- ゲームを最後まで遊ぶと、一緒に遊んだキャラクターのなかよし度が上がる（+3、1日に9まで。途中でやめたゲームは数えない）。

## 確かめ方

- `--pageone-test <out.txt>`：配り方、出せるカード、8・2（重ねて返す）・ジョーカー・J・A、引いたカードを出すか取っておくか、ページワンの宣言と指摘、上がりと点数、山札の作り直し、ゲームの終わりを、決めた並びで確かめる。1行目は失敗の数。
- `--pageone-play-test <out.txt> [count] [seed]`：キャラクターの打ち方どうし、点の高い札から出す相手、でたらめな相手とcount回ずつ遊び、カードの数が合うか・止まらないかを確かめて、勝ち負けを出す。1行目は「0 wrong」。
- `--pageone-shot out.png [steps] [seed] [help]` で2Dの画面を撮る（helpを付けると遊び方）。
- `--snapshot out.png 620 --pageone [steps]` で3Dの卓を撮る（stepsを指定すると、12秒後にその手数だけ進める）。
