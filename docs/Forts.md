# 三つの砦（ミニゲーム）の設計

キャラクターと1対1で遊ぶ、オリジナルのカードゲームです。洋風ファンタジーの世界で、3つの砦を取り合い、先に8点を取ったほうが勝ちます。洋室の卓に、キャラクターが座って相手をします。

## 方針

- **ほかのカードのゲームと同じ作り**：別のウィンドウで遊び、キャラクターはその間デスクトップから消えて、同じモデルが卓の向こうに座る。部屋は洋室（`src/WesternRoom.cpp`）。
- 右クリックメニューの「ミニゲーム」→「三つの砦をする」で、そのキャラクターが相手になる。途中のEscは、Yでやめる、Nで続ける。
- 砦と兵とカードは読みやすいように、3Dの卓ではなく画面に平らに描く。キャラクターはその奥に見える。
- カードの絵はまだなく、枠と文字だけの仮のカードで描いている（`CardFace`）。

## ルール

- **勝ち**：先に8点。自分の兵だけがいる砦が、自分の番の初めに点になる（相手に1番分、取り返す機会がある）。全部で40手を超えたら、点の多いほうの勝ち。
- **砦**：左1点、中央2点、右1点。各砦に、自分の兵は3体まで置ける。
- **準備**：デッキは30枚、手札は4枚。最初に好きな枚数だけ引き直せる。後攻は手札が1枚多く、一度だけ魔力を1増やせる。
- **自分の番**：点を数え、魔力の上限が1増えて全回復し（最大8）、1枚引く。そのあと次を好きな順に行う。
  - カードを使う。兵は好きな砦に置く。
  - 手札1枚を捨てて、この番だけ魔力+1（番に1回）。
  - 兵1体ごとに、移動（隣の砦へ）か攻撃（同じ砦の敵へ）のどちらか1回。置いた番の兵は動けない。
- **攻撃**：お互いに攻撃力ぶん、同時に体力が減る。
- 相手の番に割り込む効果はない。デッキが切れたら引けないだけで、負けにはならない。

## 能力

| 名前 | 効果 | 点数 |
|---|---|---|
| 守護 | 同じ砦の敵は、まずこの兵を攻撃する | 1 |
| 疾駆 | 置いた番から動ける | 2 |
| 飛翔 | 守護を無視して攻撃できる | 2 |
| 遠射 | 攻撃したとき反撃を受けない | 2 |
| 堅固 | 受けるダメージ-1 | 3 |
| 旗手 | 砦を押さえているとき、その砦の点+1（何体いても+1まで） | 2 |
| 斥候 | 移動のあと攻撃もできる | 1 |

カードの強さは点数で揃えている。コストcの兵は、攻撃力+体力+能力の点数の合計を 2c+1 までにする。森の民だけ1点多い（小さな体が戦いで負け通しになるため）。`--forts-test` が表の全カードを確かめる。

## デッキ

3つの勢力の10種を2枚ずつと、共通の6種のうち5種を2枚ずつで30枚。カードの一覧は `src/Forts.cpp` の `Cards`。

- **騎士団**：守りが堅く、旗手で砦の点を増やす。
- **森の民**：速さと数で、砦を次々に押さえる。
- **魔術院**：呪文で敵を崩し、手札で押し切る。

あなたはゲームの初めに選ぶ。キャラクターのデッキはランダム。

## キャラクターの考え方

見えているものだけで考える。あなたの手札は見ない。枚数と、そのデッキに入っているカードから、手札を何通りか想像して先を読む。番の初めに1つの計画を立ててそれを進め、カードを引いたら考え直す。

相手の番の初めに、次に狙う砦へ目をやり、ときどき言葉でもほのめかす。4回に1回ははったりで、本当に狙っているとは限らない。表情も形勢によって変わるが、ときどき逆の顔をする。

## 操作

カードをクリックし、光った場所（砦や相手）をクリックする。自分の兵は、クリックしてから攻撃する相手か移動する砦をクリックする。カードの上にマウスを置くと大きく見える。

- E / Enter：番を終える。G：選んだカードを魔力に変える。M：一度だけの魔力。Esc：選択をやめる（何も選んでいなければ、やめるかどうかを聞く）。Tab：遊び方。
- カメラは麻雀と同じ（右ドラッグで回す、ホイールで寄る、F1で戻す）。

## 確かめ方

- `--forts-test out.txt`：決まった盤面でルールを確かめる。先頭の行が失敗の数。
- `--forts-play-test out.txt 100 1`：自分どうしのデッキごとの勝敗、先攻の勝率、対戦の長さ、カードごとの勝率、単純な打ち方との勝敗。
- `--forts-shot out.png 手数 乱数 choose|redraw|play|unit|help`：2Dの画面。
- `--snapshot out.png 620 --forts 手数`：3Dの卓。
