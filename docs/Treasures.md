# お宝を眺める

ダンジョンから持ち帰ったお宝を、デスクトップでキャラクターと一緒に眺めます（[docs/Dungeon.md](Dungeon.md)）。

## 眺め方

- 右クリックメニューの「お宝を眺める」に、そのキャラクターが持ち帰ったお宝が、手に入れた日と一緒に並ぶ
  （2個以上なら「×2」）。まだなければ、灰色の案内だけ。
- 1つ選ぶと、キャラクターは画面の真ん中の側へ横を向き（80°）、手前側の手（右を向けば右手）を前に出して手のひらを上にする。
  お宝の絵は、その手のひらの上に乗るように、キャラクターの少し前に出る（体と重ならないように）。下にうっすら影。
- キャラクターは、いつ・何階の・どこ（宝物庫、ボスのドラゴン、宝箱）で見つけたかを話す。LLMがあれば、お宝の説明と
  手に入れたときのことを伝えて、自分の言葉で思い出話にする。ないときは「これは2026年10月27日に、20階の宝物庫で見つけた伝説の王冠だよ。」。
- 話し終えて3秒ほどしたら（最短7秒、最長30秒）、絵が消えて、手を下ろし、正面に戻る。持ち上げられたり、歩き出したり、
  ダンジョンへ行ったりしたら、すぐにしまう。眺めている間は、勝手に歩き出さない。
- **ほかのキャラクター**がデスクトップに立っていれば、そちらへ少し体を向けて（25°）お宝を見て、絵が出たところで一度のぞき込む
  （しぐさ「のぞき込む」）。その間は歩き出さない。

## お宝

絵はすべてアプリの中で図形とグラデーションで描く（画像ファイルや他の人の素材は使わない）。図鑑（ダンジョンのZ）にも、
同じ絵を並べる（まだのものは「?」）。

| お宝 | 出る階 | 手に入れ方 |
|---|---|---|
| 古代のコイン | 4階〜 | 宝物庫（8階からは、ふつうの宝箱からもまれに） |
| 星のかけら | 5階〜 | 同上 |
| 妖精の小瓶 | 6階〜 | 同上 |
| 古の指輪 | 7階〜 | 同上 |
| 銀の手鏡 | 8階〜 | 同上 |
| 月のしずく | 10階〜 | 同上 |
| 琥珀の化石 | 10階〜 | 同上 |
| 魔法の砂時計 | 12階〜 | 同上 |
| 虹色の貝殻 | 12階〜 | 同上 |
| 精霊のオルゴール | 14階〜 | 同上 |
| 女神の羽根 | 16階〜 | 同上 |
| 古代竜の牙 | 18階〜 | 同上 |
| 伝説の王冠 | 20階〜 | 同上 |
| 竜のうろこ | 5階〜 | ボスのドラゴン |
| 黄金の聖杯 | 15階〜 | ボスのドラゴン |

- 宝物庫の宝箱は、4階から40%がお宝。まだ持っていないお宝が、少し出やすい。
- 記録（`characters\<モデル名>-<番号>.dungeon.txt`）に、最初に手に入れた日・階・場所と、数を残す
  （`treasure.<id>=日付|階|場所|数`）。前の形式（`=1`）のものは「日付不明」として読む。
