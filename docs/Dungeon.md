# ダンジョン（ミニゲーム）の設計

キャラクターと一緒に、ランダムに作られるダンジョンを冒険するローグライクです。いまは**試作**です。
遊んでみて、手応えを見ながら足していきます。

## 方針

- **別のウィンドウ**で遊ぶ。デスクトップは覆わず、いつでも閉じてやめられる。
- **ターン制**。こちらが1歩動くと、モンスターも1歩動く。アクションが苦手でも遊べる。
- **装備は持ち越さない**（毎回、素手から）。やりこみは、深い階・記録・図鑑・称号・今日のダンジョンで作る。
- 1フロアは数分で遊べる大きさ（集中モードの休憩でも遊べるくらい）。
- **キャラクターと一緒にいること**を生かす：しゃべる、休む、写真に残す、なかよし度で少し助けてくれる。

## ダンジョンの基本

- **ダンジョン**：4×3のマスに部屋を1つずつ置き、隣どうしを短い通路でつなぐ（全部の部屋がつながる木と、
  少しの余分な通路）。スタートは1つの部屋、階段（ゴール）はそこからいちばん遠い部屋。
- **見える範囲**：いる部屋は全体が見える。床が続いている所は5歩先まで見える（通路では曲がり角の先まで、部屋からは出入口の先の通路も）。一度見た所は暗く地図に残る。
- **移動と攻撃**：矢印キーかWASDで上下左右に1マス。モンスターの方へ動くと剣で攻撃。
  スペースで1ターン待つ（そのとき、まわり8マスの罠を見つける）。押し続けても1ターンだけ（もう一度押すと、もう1ターン）。
- **魔法**：Fキーで、向いている方向へ魔法を放つ（7マス先まで、最初に当たったモンスターに。MPを3使う）。
  杖を持つと魔力が上がる。
- **宝箱**：踏むと開く。回復薬、魔法の水、骨付き肉、武器（剣・杖）、防具、アクセサリ。深い階ほど良いものが出る。
- **持ち物**：10個まで。数字キー（1〜9、0）で使う・食べる・装備する（装備中のものを選ぶと外す）。
  装備していない枠には、拾ったときにそのまま装備する。装備しても見た目は変わらない。
  Shift＋数字キーで、お店の部屋では半値で売り、それ以外では捨てる（装備中なら外して）。
- **能力**：HP・MP・攻撃・防御・魔力とレベル。モンスターを倒すと経験値が入り、レベルが上がる。
- **モンスター**：見つかるまで眠っていて、こちらが見えると近づいてくる。深い階ほど強い。倒すとゴールドを落とすことがある。
  種類ごとに動き方が違う。

  | モンスター | 動き方 |
  |---|---|
  | スライム | 遅い（2ターンに1歩）。攻撃されて生き残ると、40%で2匹に分裂する（1回だけ。分かれた方は経験値が半分） |
  | コウモリ | 40%でふらふらと関係ない方へ飛ぶ |
  | ゴブリン | 隣にいると20%でゴールドを盗み（持っている分の20〜40%）、1ターンに2歩で逃げる。倒せば取り返せる。8ターン逃げ切ると、ゴールドを持ったまま消える |
  | ガイコツ | 倒すと、50%で崩れたあとまた組み上がる（HP半分、1回だけ） |
  | オーク | 隣にいると35%で力をためる。次のターンに隣にいれば、1.8倍の一撃。離れればためた力はなくなる |
  | ゴーレム | 遅い（2ターンに1歩）が、硬くて強い |
  | ゴースト | 壁をすり抜けて近づく（壁の中からは攻撃できない。剣は壁の中のゴーストにも当たる） |
  | ドラゴン（ボス） | 巨大で、3×3の9マスを占める（部屋に入りきらないときは1マス）。体のどのマスを攻撃しても当たり、体のふちの隣に来ると攻撃してくる。体のふちから見てまっすぐ並んで2〜5マス、間に壁がないと、50%で炎を吐く（4ターンに1回まで）。3Dでは炎が床を走る |

  5階ごとに、階段のある部屋にボス（ドラゴン）がいて、倒すまで階段を使えない。
- **階段**：Enterで次の階へ、Bでデスクトップに帰る。Escでいつでもやめて帰れる（確かめてから。帰るのはYだけで、Enterでは帰らない）。
- **やられたら**：「やられてしまった…」を1.5秒は出したままにし、そのあとEnterかEscで帰る（戦いで押し続けた・連打したキーで、見ないうちに帰ってしまわないように。スペースでは帰らない）。
- ダンジョンにいる間も、デスクトップにいる他のキャラクターは、あいさつや知らせを話せる（ダンジョンのキャラクターの言葉にはじゃまされない）。
- **帰ってきたら**：キャラクターが、何階まで行ったか（やられたか）、新しい称号を話す。

## しゃべるダンジョン

- キャラクターの言葉は、3D（2D）の下の**吹き出し**に出る。顔は、デスクトップで最後に描いた姿から切り出す。
- 新しい階に着いた、新しい部屋に入った（階段・宝箱・モンスターが見えた）、レベルが上がった、罠を踏んだ、HPが減った、
  ボスを見つけた・倒した、焚き火で休んだ、宝物を見つけた、称号をもらった、やられた…などで話す。
- **LLMがあるとき**は、そのときの出来事（と、いまの階・HP・レベル、さっき言ったこと）を伝えて、キャラクター自身の言葉で話す。
  人物設定となかよし度の話し方に合わせる。返事を待つ間は「…」。9秒来なければ、用意したセリフにする。
  小さな出来事は12秒に1回まで（それ以外は用意したセリフ）。大事な出来事（ボス、焚き火、やられた等）は毎回。
  表情もLLMの気持ちの印で変わる。音声の設定があれば声も出る。
- LLMがないとき・使えないときは、出来事ごとに用意した何通りかのセリフから選ぶ。
- 軽い出来事は、大事なセリフを3秒以内に上書きしない。

## 罠

部屋の床に隠れている（スタートの部屋・お店・宝物庫・焚き火の部屋にはない）。踏むか、スペースで探すと見えるようになる。

| 罠 | 踏むと |
|---|---|
| トゲ | ダメージ（3＋階の半分） |
| ワープ | 同じ階の別の部屋へ飛ばされる |
| 落とし穴 | 2のダメージで、下の階に落ちる |
| 警報 | 階じゅうのモンスターが目を覚ます |
| 眠りガス | 少し眠り、その間モンスターが2回動く |

## 特別な部屋

| 部屋 | 出る階 | 中身 |
|---|---|---|
| 焚き火 | 2階から40%（ボスの1つ前の階には必ず） | 焚き火に向かって進むと休む：HPとMPが全回復（1回だけ。近くに起きたモンスターがいると休めない）。キャラクターが冒険のことを2〜3文で話す。焚き火の隣でCキーを押すと、入力欄でキャラクターと話せる（下の「焚き火で話す」） |
| お店 | 2階から35% | 床に3〜5個の品物。乗るとEnterで買える（ゴールドはモンスターと床から）。ゴールドが足りない・持ち物がいっぱいのときは、キャラクターがそう言う。お店の部屋の中では、Shift＋数字キーで持ち物を半値で売れる |
| 宝物庫 | 3階から30% | 入口が鍵のかかった扉。同じ階のどこかにある鍵で開く。中は良い宝箱2〜3個（6階からは宝物も） |
| モンスターハウス | 4階から22%（ボスの階を除く） | 眠ったモンスターが6〜9匹。入ると全員起きる |
| 暗い部屋 | 3階から25% | 部屋全体は見えず、まわりの数歩だけ見える |
| 水晶の部屋 | 2階から20% | 光る水晶が並ぶきれいな部屋（写真を撮る） |

宝物庫はどの部屋への道もふさがない部屋だけが選ばれ（階段や他の部屋には、扉を開けずに行ける）、鍵は必ず同じ階にある。

## おなか（満腹度）

- 100%から、12ターンに1%ずつ減る（1200ターンで空になる。1階はふつう数百ターン）。
- 骨付き肉（+50%）、大きな骨付き肉（+100%）で戻る（持ち物の数字キーで食べる）。宝箱とお店に出る。
  2階からは、7割の階に骨付き肉の入った宝箱が1つある。おなかが40%以下で食べ物を持っていないと、宝箱の半分は食べ物になる。
  モンスターを倒すと、8%で骨付き肉を落とす（持ち物に空きがあれば拾う）。
- 20%になると、キャラクターが知らせる。骨付き肉を持っていれば何番のキーで食べられるかを、なければ宝箱やお店で探そうと言う。
- 空になると、自然に回復しなくなり、4ターンに1ずつHPが減る（1より下にはならない）。控えめにして、急かしすぎない。

## なかよし度で少し助けてくれる

なかよし度の段階（[docs/Bond.md](Bond.md)。数えていないときは0）で、少しだけ有利になる。冷たくても不利にはならない。

| 段階 | 効果 |
|---|---|
| 1以上 | 宝箱から、おまけの回復薬を見つけることがある（段階×7%） |
| 2以上 | モンスターの攻撃をかわすことがある（段階×2%） |
| 3以上 | 焚き火で休むと、最大HPが3増える |
| 4（相棒） | 1回の冒険で1度だけ、やられそうになってもHP1で踏みとどまる |

ダンジョンから帰る（30ターン以上の冒険）と焚き火で休むたびに、なかよし度が+3（1日9まで）。

## 写真（アルバム）

- Pキーで、いまの3Dの画面をアルバムに残す（シャッター音の設定に従う）。
- 自動でも残す：ボスを倒した、焚き火で休んだ、水晶の部屋に入った、宝物を見つけた、いちばん深い階を更新した。
  出来事の2.5秒後に撮る（キャラクターがそちらを向き、セリフが出てから）。
- 3Dの画面だけを写す（デスクトップや他のウィンドウは写らない）。セリフは album.txt に残る。

## 記録・図鑑・称号

- Zキーで「冒険の記録」：いちばん深い階、冒険した回数、今日のダンジョンの記録、
  **図鑑**（倒したモンスターと数、見つけた持ち物、宝物。まだのものは「？？？」）、**称号**（取り方のヒントつき）。
- **宝物**（15種類）は持ち物に入らず、持ち帰って記録される。宝物庫の宝箱（深い階ほど珍しいもの）とボスから。
  図鑑には絵で並び、デスクトップの右クリックメニュー「お宝を眺める」で、キャラクターが手のひらに乗せて見せてくれる
  （[docs/Treasures.md](Treasures.md)）。
- **称号**（17個）：初めての冒険、5階・10階・20階、ドラゴン退治、剣ひとすじ（魔法なしで5階）、大魔法使い（1回で魔法で20匹）、
  無傷の踏破、モンスターハウス制覇、宝物庫の主、お得意様（5回買う）、罠に好かれる者（10回踏む）、焚き火の語らい（5回休む）、
  コレクター（持ち物20種類）、モンスター博士（全種類を倒す）、宝物ハンター（宝物全部）、今日も冒険。
- 記録はキャラクターごとに `characters\<モデル名>-<番号>.dungeon.txt`（UTF-8の `キー=値`）。
  何か起きるたびに保存するので、途中でアプリを閉じても失われない。前の形式（`best=N` だけ）もそのまま読める。

## 今日のダンジョン

- 1階でまだ動いていないうちにTキーを押すと、**今日のダンジョン**になる。その日の日付から作るので、
  一日じゅう同じ階が出る（何が起きたかに関係なく、階ごとに同じ）。
- 最深記録とは別に、今日のダンジョンの記録を残す（日付が変わるとリセット）。

## 3D

- 視点は三人称。Vキーで、斜め見下ろし（シレン風）と背後から（原神風）を切り替える。カメラはなめらかに移る。
  背後からのときは、↑で向いている方へ進み、←→でその場で向きを変え、↓で振り向く（向きを変えるだけならターンは進まない）。
- キャラクターは、1マス進むたびに歩く。体を横に向けず、向いている方へ足を運ぶ歩き方（生成モーションの「前向きの歩き」）で、
  足の運びと同じ速さで進むので足が滑らない。デスクトップより歩幅はそのままで、足の運びを1.4倍速くしている。
  キーを押し続けると、0.25秒で走り出し、離すまで走り続ける（走る速さより速くはならない）。新しい階やワープでは、着いた場所にすぐ立つ。
  歩いている途中に押したキーは、その1歩が終わったときにまだ押されていれば次の1歩になる。
  走るときは手を軽く握り、腕を振るのに合わせてひじを曲げ伸ばしするので、こぶしが胸と腰の間をリズミカルに上下する（デスクトップで走るときも同じ）。
- 攻撃のしぐさ（どちらも全力で）：剣は、右のこぶしを頭の後ろまで振りかぶり（体を反らし、その肩を引く）、右足を踏み込んで腰を落とし、
  体を前に倒しながら目の前へ振り下ろす（打ち込む瞬間に向けて速くなる）。反対の腕は後ろへ振れる。振り抜いた形で少し止まってから戻る。
  剣は光の粒でできた刃で、前腕の先に伸び、振り下ろす間は切っ先の軌跡が残る。
  魔法は、両手を体の横に引いて手のひらを合わせ（腰を落として反る）、踏み込みながら両手を前に突き出す。両手の間に光が集まり、
  光の玉が山なりに（背後から見てもキャラクターの頭の上に見えるように）飛んで、魔法の届いたマスではじける（3Dでは道筋の印は出さない）。
  しぐさは止まってから始まり（歩いている途中なら、着くのを少し待つ）、振っている間に押したキーは振り終わるのを待つ。
  攻撃の結果（モンスターが倒れて消える、動く）は、剣が振り下ろされたとき・魔法の光が届いたときに3Dに出る（それまでは前のまま）。
  当たったところで光の粒がはじけ、倒したときは大きく紫がかった粒が散る。
- 床と壁は、マスごとの石畳とレンガ積みの模様を、シェーダーで位置から作る（テクスチャの画像を持たないので、メモリを使わない）。
  キャラクターの周りをたいまつのように照らし、離れるほど暗くする。壁は1マスまるごとの岩で、キャラクターの身長の2倍ほどの高さ。
  レンガは色あせていて、しみ、上から流れた水の筋、足もとの汚れ、ところどころの苔がある（どれもシェーダーで位置から作る）。
  床の石畳も同じように色あせて、しみ、湿った黒ずみ、目地の汚れと苔がある。
  背後からのときは壁を低くせず、後ろに壁があればカメラがその半マス手前まで寄る（2マス後ろが壁なら、すぐ後ろのマスの真ん中。近いほど少し低く。寄るのはすぐ、離れるのはなめらかに）。
  すぐ後ろのマスが壁のときは、一人称（キャラクターの目の高さから向いている方を見る）になめらかに移り、そこから離れると戻る。
  カメラが三人称の最も近い位置（0.6マス）より内側に入っている間はキャラクターを描かないので、切り替えの途中で体の内側が見えることはない。
  斜め見下ろしのときは、キャラクターとカメラの間の壁を低くする。キャラクターが歩くにつれ、またカメラを切り替えるにつれて、なめらかに沈んだり伸びたりする
  （高さは頂点シェーダーが、描かれている位置とカメラの向きから毎フレーム決める）。低くする壁は（斜め見下ろしでは、キャラクターより地図の下にあって、すぐ上が床の壁と、キャラクターの真下の列で3マス以内の壁。通路の左右の壁は低くしない）。
  背後からのときだけ、壁の上に天井がある。扉はキャラクターより少し高く、その上は天井までレンガ。
- 5階ごと（ボスの階まで）に、壁と床の見た目が変わる（どれもシェーダーで位置から作る。26階からはまた最初から）。

  | 階 | 見た目 |
  |---|---|
  | 1〜5 | 古いレンガの地下道：色あせたレンガと石畳 |
  | 6〜10 | 苔むした石の遺跡：大きな切り石の壁、苔の生えた丸石の床 |
  | 11〜15 | 氷の洞窟：霜のついた岩の壁、ひびの入った氷の板の床（ところどころきらめく） |
  | 16〜20 | 溶岩の洞窟：黒い岩の壁と床、そのひびと継ぎ目が赤く光る |
  | 21〜25 | 紫水晶の深淵：金の枠の磨いた石板の壁、市松模様の大理石の床 |

- モンスターは種類ごとの形（MonsterArt）で、キャラクターの方を向く。スライムは目のあるしずく、コウモリは翼を広げて宙に浮き（床に影）、
  ゴブリンはとがった耳と鼻にナイフ、ガイコツは骨と赤く光る目にさびた剣、オークは大きな体に牙と棍棒、ゴーレムは石の塊に光る紋様、
  ゴーストは光る青白い体（壁の中では見えない）、ドラゴンは4本足に長い首としっぽ、角、背中のとげと大きな翼（9マスに広がる大きさ。2Dの地図でも9マス分）。
  表面には汚れ（しみ、細かいざらつき、垂れた筋、足もとの泥）があり、模様はモンスターの体に付いているので、動いてもずれない（光る目や青白いゴーストは除く）。
  宝箱、モンスター、罠、焚き火、品物、扉、水晶なども、箱の組み合わせで描く（光るものは明かりの影響を受けない）。
- キャラクターは、ダンジョンにいる間デスクトップから消え、同じモデルをダンジョンの中で描く（PMXやモーションを二重に読み込まない）。
- **メモリ**：3Dの描画の準備（描画先、ダンジョンの形、モデルのテクスチャ）は、ダンジョンのウィンドウを開いたときに作り、閉じたときに捨てる。
  セルフシャドウとモーションブラーは使わない（影のための領域も最小）。アンチエイリアスとテクスチャの大きさは、デスクトップの設定に
  合わせる（ただしアンチエイリアスは4倍まで、テクスチャは1024まで）。設定の「詳細」の「3Dを軽く表示する」をオンにすると、
  アンチエイリアスなし、テクスチャ512、解像度75%で描く（次に開いたときから）。
  1人のモデル（アンチエイリアスなしの設定）で、開いている間だけGPUの専用メモリが約75MB（軽く表示で約45MB）、共有メモリが約20MB増え、
  閉じると戻る（何度開いても増え続けない）。
- Mキーで2Dの地図と切り替えられる（比べるため）。

## 焚き火で話す

焚き火の隣（見えるところに起きたモンスターがいないとき）でCキーを押すと、ログの場所に入力欄が開く。
書いてEnterで話しかけると、キャラクターが吹き出しで1〜3文で答える（LLMで。使えないときはそう言う）。
LLMには、キャラクターの設定、なかよし度、ここまでの冒険（階・レベル・HP・ゴールド・倒した数・最高の階・最近のできごと8つ）と、
その焚き火でのそれまでの会話（16個まで）を渡す。Escか、焚き火から離れる・モンスターが見えると閉じて、会話は忘れる。

## 後で足すもの

- キャラクターの衣装の色など、深い階での見た目の解放。
- 職業やダンジョンの種類の解放、難しさのランク、未鑑定や呪いの装備。
- 宝箱やモンスターの形をもう少し凝る。
- 複数のキャラクターでパーティ。
